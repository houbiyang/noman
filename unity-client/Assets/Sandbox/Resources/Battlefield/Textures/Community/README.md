# 社区 PBR 表面资源

本目录实际导入 ambientCG 的七组 1K 材质：Grass004、Asphalt012、Bricks075A、Concrete034、Plaster001、Metal032、Wood051。每组使用底色与 OpenGL 法线贴图；没有导入源包中的位移、粗糙度或预览图，也没有启用几何位移。

作者：ambientCG / Lennart Demes。许可证为 CC0 1.0 Universal，可用于商业项目和源文件分发。官方说明：https://docs.ambientcg.com/license/ 。逐项原始链接及下载压缩包 SHA-256 见同目录 `sources.json`。

使用现有 URP Lit 着色器与既有纹理导入设置，不增加包依赖。住宅、公寓、办公楼、仓库、兵营、机库、储罐、桥梁、加油站、公园及农业设施按表面材质共享这些贴图。玻璃、水面、瓦片、植被叶片和焦黑战损继续使用工程既有表面；本次没有替换建筑几何模型。

检索过 Unity Asset Store 的 Yughues Free Ground Materials：https://assetstore.unity.com/packages/2d/textures-materials/nature/yughues-free-ground-materials-13001 。商店页面采用 Standard Unity Asset Store EULA；该包未领取或导入，不计入本次交付。

社区纹理用于 Unity 实时渲染。此前生成的 Blender 离线图仍使用原有材质，不作为此次社区材质效果证明。

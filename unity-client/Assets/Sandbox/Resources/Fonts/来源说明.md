# 网页中文字体

- 资源：Noto Sans CJK SC Regular，原始文件未经修改。
- 上游项目：https://github.com/notofonts/noto-cjk
- 文件来源：https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf
- 许可证：同目录 `LICENSE.txt`，SIL Open Font License 1.1。构建入口会复制到网页产物 `ThirdPartyNotices/NotoSansCJK-LICENSE.txt`。
- 用途：Unity Web 字体资源；不使用在线字体服务，不复制或分发 Windows 系统字体，不增加代码包依赖。
- 浏览器存档名称和中文文本从同一个字体动态生成字形，避免仅烘焙固定界面文字造成输入缺字。

# 历史记录与演示结果：设置内嵌与操作简化验收

日期：2026-11-11。本记录以本次简化后的控件为准，替代此前的多按钮清单。

## 保留的界面与数据边界

- 两页继续嵌入设置右侧，复用深绿色指挥台、大尺寸居中面板、金色强调和背景遮罩。
- 切换页签、档案来源、预演场景不替换或保存设置草稿。
- 外层纵向滚动，档案表内部横向滚动；滚轮步长10。
- 服务端席位档案、本机观察档案、规则预演分开；预演不写服务端，不冒充真实战果。
- 历史仅供查阅，不是录像，也不是可恢复快照。

## 操作简化

### 历史记录

| 控件 | 行为与约束 |
|---|---|
| 档案来源下拉 | 服务器模式下在服务端历史、本机/规则预演间切换；替代两个切换按钮，自动读取对应数据并清理旧详情 |
| 记录状态下拉 | 全部记录/进行中/已结束；替代三个按钮，切换时回第一页 |
| 名称搜索 | 本机输入即筛选；服务端回车或离开输入框后自动查询，无独立“查询”按钮 |
| 归档当前对局 | 仅服务端历史保留；名称留空自动生成，可选自定义名称收进折叠项；需健康、空闲、无待决命令 |
| 刷新记录 | 仅服务端保留用于重新读取与失败重试；移除本机刷新，返回历史页自动重读本机数据 |
| 查看档案/收起档案 | 同一行按钮切换详情，不再另外放“收起详情”按钮 |
| 查看计算过程与关键节点 | 从档案详情转入只读结果，沿用该档案证据，不替换为预演 |
| 上一页/下一页 | 仅超过20条时出现，第一页/末页禁用相应操作 |

本机历史删除“按席位查看”概览卡和“档案管理”整栏，包括手动归档、自定义名称入口及栏内说明；不改变按席位过滤的数据边界。保留档案总数、状态统计、搜索筛选、列表详情、独立提示和结束自动归档，已有档案不删除。

删除历史页的“可恢复存档…”重复入口；恢复仍可从沙盘原有“存档”入口使用。不提供历史删除操作，避免把不可变档案误当可编辑存档。

服务端读取与轮询共用传输：忙碌时排队；读取中更改条件也保留最新查询，旧响应不覆盖新条件结果。切到其他设置页后，异步响应不会把用户抢回历史页。失败保留已有记录，并可刷新重试。

### 演示结果

| 控件 | 行为与约束 |
|---|---|
| 查看内容下拉 | 当前对局、7:9预演、9:9平局、40分钟未结束，合并原有两个来源按钮与三个场景按钮；查看历史时额外显示“历史档案（只读）” |
| 保存预演到历史 | 仅独立规则预演显示；位于顶部主操作区，只写本机；已归档证据不重复显示保存按钮 |
| 本方投降… | 仍由服务端能力控制，开始5分钟后仅本方席位可用；二次确认不删除 |
| 确认本阶段裁定… | 仅旧45分钟规则的主持人能力允许时显示；阶段和六个目标依据必填，仍需二次确认 |

移除与左侧导航重复的“历史档案→”。常规预演页的按钮由原先7个（来源/历史入口/场景/保存）减至1个，不计共用设置导航和底栏。

设置打开期间完整拦截沙盘点击，包括挂在Panel根节点的下拉弹出项，防止选择场景时穿透到单位并关闭设置。

下拉框及其弹出菜单均采用深绿底色、浅色文字、金色选中态；加宽选项区域，避免长场景名称被横向截断。

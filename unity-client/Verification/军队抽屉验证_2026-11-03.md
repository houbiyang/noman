# 军队配置右侧抽屉验证

日期：2026-11-03。Unity 6000.6.7f1 ARM64，macOS；Chrome 加载本机 Unity Web 构建。

## 界面调整

- 原居中大弹窗改为右侧纵向抽屉，宽度 398 个界面单位，随 Unity 面板缩放；不再创建整屏遮罩。
- 三种单位纵向排列，使用模型缩略图；每张卡片保留名称、已部署数量、新增数量加减和「选点部署」。
- 移除英文分类、宣传副标题、模型长介绍、图片注释和重复操作说明。
- 顶部保留关闭、当前阵营、主持人阵营切换及「管理单位」入口。底部固定显示红蓝共享容量、剩余名额和集结区部署按钮。
- 卡片区域单独滚动，抽屉外可拖动地图；Esc 或关闭按钮退出抽屉。

## 实际验证

| 项目 | 结果 |
| --- | --- |
| Unity Web 构建 | 成功，退出码 0；日志 `.local/unity/BuildWeb-macos.log` |
| 1188×898 | 抽屉约占窗口三成宽度，三张卡片完整显示，地图保持可见 |
| 1024×600 | 卡片可滚动至保障车部署按钮，顶部与底部保持固定且可用 |
| 1600×900 | 抽屉保持窄宽度，卡片可滚动，数量控件和部署按钮可用 |
| 数量与追加部署 | 侦察机数量从 1 调至 2，选点部署后总数由 6 变 8，本方侦察机由 1 变 3，原单位保留 |
| 单位管理与删除 | 从「管理单位」进入原单位面板，确认删除 R-U01，再开军队抽屉显示总数 7、剩余 3 |
| 集结区部署 | 将三张卡片数量调至各 1，部署后地图总数为 10，所有新增按钮及数量加减禁用 |
| 主持人阵营切换 | 可在抽屉内切换红蓝编队，各自数量正确，双方共享满额状态 |
| 地图与退出 | 抽屉开启时可拖动外部地图，抽屉区域仍拦截地图操作；Esc 及关闭按钮可退出 |
| 浏览器异常 | 未捕获 JavaScript 异常；控制台仅有 favicon 404 |

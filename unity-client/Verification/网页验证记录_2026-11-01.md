## 本次环境与实现

- Unity `6000.6.7f1`，已有 WebGLSupport 模块。本次只读查询确认 Unity Personal 许可证已激活，不代为操作账号或接受许可。
- 通过 Unity 原生命令行和编辑器 API 构建，不增加 Pipeline、UPM、npm 或 Python 包。
- 网页中文使用原始 Noto Sans CJK SC Regular 字体资源，附上游 SIL OFL 1.1 许可证；未复制或分发系统字体。
- 网页存档由实际 `.jslib` 写入 `localStorage`，按站点及网址目录隔离；写入失败不退出，不覆盖同编号记录。桌面文件存档流程保留。
- 网页退出释放 Unity 实例并显示重新进入入口；保留取消操作。
- 网页模板包含实际加载进度、错误提示、重试、全屏和地图右键菜单屏蔽。
- `start-web.ps1` 使用本机已有 Python 标准库提供 HTTP，只监听 `127.0.0.1`，服务根目录限定为 `Builds/Web`，不提供工程源码目录。通过路径摘要识别本工程服务，不关闭其他进程。

## 浏览器黑屏修复与实际运行复验

用户反馈网页黑屏后继续授权排查，本节记录后续实测，覆盖上一节尚未验收的对应项目。

- 浏览器实际错误为 `InvalidOperationException: 请使用本工程自带 URP 配置打开场景`，发生在 `SandboxWorld.CreateMaterial`。核对工程实际安装的 URP 源码，`UniversalRenderPipelineAsset.GetMaterial` 在非 Editor 条件下返回空；原代码依赖 `pipeline.defaultMaterial`，使启动中断于相机与 HUD 创建之前。
- `SandboxWorld.cs` 改用地图持久材质已经引用并随包发布的 `Universal Render Pipeline/Lit` 着色器创建材质；没有改地图布局或业务规则。
- 首次浏览器复验已经恢复地图与中文界面，但发现 `CreatePrimitive` 间接需要的 `SphereCollider`、`CapsuleCollider` 被裁剪。新增 `Assets/Sandbox/link.xml` 仅保留这两种组件，避免动态模型创建时的组件缺失错误。
- 最终 Web 构建退出码 0。产物 8 个文件，共 27,120,396 字节；实际 HTTP、Gzip、脚本及 WebAssembly 编译检查重新通过。
- 在本机内置浏览器中实测：青岚河谷三维地图与中文 HUD 显示、角色切换、缩放、无人机跟随均正常；验证过程中保存 1 条前端快照，刷新并加载最终版本后仍可枚举该记录，点击确认恢复后显示“已恢复本地演示快照，保持暂停”。该验证存档保留在当前浏览器。
- 最终启动日志时间为 `2026-11-01T02:03:17Z` 起，筛选此后错误级别日志为 0；旧启动的报错仍保留在日志历史中，没有将旧日志误认成最终版本结果。
- 浏览器仍有模板内未启用后处理着色器及 ICU 降级提示。本次已看到中文正常显示，不把这项实测扩大为任意中文输入、全部字符排版和全部后处理验收。

## 地图鼠标拖动、旋转和缩放

- 左键单击选择单位；移动超过阈值后进入平移，不在松开时误选单位。中键继续支持平移。
- 使用屏幕射线与观察中心水平面的交点差进行平移，旋转之后仍按鼠标屏幕方向拖动。观察中心限定在地图范围内。
- 右键左右拖动旋转，上下拖动调整俯仰；俯仰保留 18 至 78 度范围。

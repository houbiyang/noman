# 已部署单位删除验证记录

日期：2026-11-03。Unity 6000.6.7f1 ARM64，macOS；Chrome 加载本机 Unity Web 构建。

## 功能与规则

- 「军队 → 管理已部署单位」或底部「单位」面板内，每个单位提供「删除单位」，确认窗口展示编号和名称；取消保留原状态。
- 红蓝双方只能删除本方单位，主持人可删除双方单位；初始单位及移动中的单位均可删除。
- 删除移除指定单位模型及其独立移动路径，释放一个共享部署名额，保留其余单位、位置及移动目标。删除跟随中的单位会退出跟随；无单位时清除选择。
- 红蓝双方地图总上限仍为 10。允许删除某类型最后一个单位、某方全部单位或清空地图；删除后的状态可保存与恢复，空地图可重新部署。
- 不存在的编号、重复删除及无权限请求不改变地图、记录或剩余名额。

## Chrome 实际交互

1. 军队配置显示「管理已部署单位」，单位卡片显示红色「删除单位」按钮。
2. 对 R-U01 打开确认窗口并取消，地图仍为 6 / 10，剩余 4。
3. 跟随 R-U01 后确认删除，退出跟随，模型、标签及卡片移除，其他模型保留；地图变为 5 / 10，剩余 5。
4. 删除剩余两个红方单位后，红方列表为空，显示「尚未选择单位」，跟随按钮禁用；地图总数 3，剩余 7。
5. 主持人删除全部蓝方单位后，地图为 0 / 10，剩余 10。空地图事件面板正常提示无可选单位。
6. 保存空地图前端快照，浏览器存储中的 `snapshot.units` 为 `[]`。
7. 选择 10 架侦察无人机并选点部署，实际出现独立模型，军队页显示 10 / 10、剩余 0，并禁用新增按钮。
8. 恢复此前的空地图快照，模型再次全部清除，军队页显示 0 / 10、剩余 10。
9. 浏览器未捕获 JavaScript 异常；控制台仅有 favicon 资源 404。

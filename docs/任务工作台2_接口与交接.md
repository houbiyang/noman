## 2. 已落盘最终Motion契约

`Motion(trace, segments=(), progress=None, finished=False, surface_id=None, interrupted=False, budget_segments=None)`：

| 字段 | 类型/语义 |
| --- | --- |
| trace | tuple；起点恰等权威position_mm，末点为本步实际已记录毫米规则位置，含x_mm/z_mm/height_mm；1–128点 |
| segments | tuple；**实际累计路径记录增量**。单段可有理毫米（跨地表精确分摊），合计为整数毫米；不按每个内部几何切段取整 |
| budget_segments | tuple或None；当步连续预算证明，可含不足1mm连续运动。None仅兼容旧合成fixture；生产ground/air都显式提供tuple |
| progress | dict或None；仅同一未中断路线的预算/几何游标，不是另一套权威位置 |
| surface_id | str或None；本步实际权威位置所在层，先持久，再处理结束/中断；生产适配器显式填写 |
| finished | bool；路线到达，清movement意图和两种余数状态 |
| interrupted | bool；受阻、耗尽、碰撞或静止不可移动分支；清余数，可保留movement意图供之后从权威毫米位置重新尝试 |

普通5秒尚未完成：finished=False、interrupted=False，保留同路线cursor。无movement、起降/landing、服务锁定或步开始失能等静止分支中断cursor。新movement（包括stop、重发同目标、换路线）由Executor `_adopt`调用`Geometry.clear_movement`，取消旧路线预算。

`clear_movement(unit)`返回deepcopy，仅删除`movement_progress`和废弃的`geometry_position`；Executor核验它不得改坐标、surface、资源或其他状态。停止/受阻/到达/取消/退役均不能跨边界恢复亚毫米起点。

### progress与FIFO

工作台1提供：

```python
record_path_segments(segments, progress=None, *, interrupted=False)
# -> (billed_tuple, pending_list, recorded_total_mm:int)
pending_path_energy(kind, progress)  # -> Fraction
```

- `rule_position_mm`：完整权威位置字典，必须恰等trace[-1]；这是cursor与权威mm的绑定。
- `exact_position_m`：两个有理数字符串，仅连续预算端点，不供观察/射击/服务/占点判定。不能通过round(exact*1000)==权威mm代替绑定；斜线即便累计路径整mm，其二维坐标仍可非整mm。
- `path_pending_segments`：同路线不足1mm的FIFO尾段（可跨地表标签）；`recorded_distance_mm`为累计已记录整数mm。
- 每段`length_mm`、surface、grade_squared以及`path_start_m/path_end_m/path_surface_id/path_begin_seconds/path_end_seconds`保留原地表/坡度/几何证据。
- helper拼旧pending与新连续段，FIFO消费floor(total_mm)，不足1mm尾部只留在该路线；终止丢尾。收费段合计整mm，各地表内仍精确有理分摊。
- 新progress绑定目录摘要、层、route摘要、leg_start/length/distance和权威规则点。旧geometry_position不得隐式迁移；非毫米legacy交互位置拒绝。

Executor复算helper账单、pending、recorded_total与规则点，防漏收、重复收费或篡改；只对budget_segments做5秒授权/能源验证，即使记录距离为0仍核验预算且不能算全步静止。新预算先预留旧pending精确费用，ground移动射击统一乘5/4预留；实际账单只用movement_cost(segments)，移动射击附加费用继续由统一内核处理。

例：ground连续3步预算各33333又1/3mm，记录33333/33333/33334mm；第3步33334不能再单独按5秒截断。air对应66666/66667/66667mm。正常cursor连续保留预算，终止则从最后已记录毫米点清尾重启。

## 3. 空地行为及保守限制

- ground使用工作台1MapMotion；连续预算扫掠和实际已记录毫米扫掠均独立证明支撑、权限、静态实体与敌军碰撞；友军按总册不互阻。
- air不送进地面移动器；预算扫掠和实际毫米扫掠都证明完整允许空域、禁飞排除及规则锚点支撑，固定leg length防JSON恢复后重算长度漂移；landing/不能移动清尾不移动规则点。
- 默认路线仅同显式层候选直线，不自动寻路、不猜最近层、不授桥头连接；air跨锚点层当前保守拒绝`BATTLE_AIR_ANCHOR_LAYER_MISSING`。
- air非法完整扫掠当前拒绝该技术事务，不宣称已实现任意空域边界自动截停/跨层航路；空域来源和锚点实体外资格仍需实地图独立证明，单个solid_volumes_validated布尔值不是网格验收证据。
- 服务≤100m、真实完整支撑扫掠和正确层；据点要求中心在冻结有效mask/圆/层及完整占地，全步驻留另受Executor stationary资格约束。
- 飞行美术高度不增视野。交互只读position_mm，不读cursor精确点。
- `load_server_geometry`为显式离线入口，注入MapDeployment要求的dock_airspace_validator；不存在客户端上传验收/目录后自动开局的接口。

# 真实支撑占地证据与桥头阻断

日期：2026-11-16；分支 `codex/ditu`。本次只读核验现地图，没有修改地图、场景发布状态、用户数据库、服务进程或WebGL包。

## 本次实现范围

- `backend/battle_support.py`：明确选择支撑部件，惰性提取真实三角形；对3～16顶点的凸多边形进行完整面积覆盖证明。使用有理数裁剪和差集，重复/交叠三角形不能累计面积掩盖缺口，不以中心或间隔采样代替完整占地。
- 检查三角面交叠、共边及点接触处的真实高度一致性；发现不同高度不能按部件ID取一层，也不能将相邻但有台阶的面认作连续坡道。高度范围只计算占地内实际接触位置，坡度证据汇总所有接触支撑面。
- 垂直/退化面单独报告，不能当作零坡度支撑；越出12000米作战边界的远景面不能使占地合法。预算超限失败关闭。
- `backend/battle_terrain_assets.py`增加只读部件ID、真实xz包围盒、面数量/顶点访问接口，保留原始资产摘要验证。
- 结果是几何证据，始终 `production_ready=false`、`grants_route_permission=false`、`overlays_resolved=false`、`collisions_validated=false`。它不是圆形单位完整扫掠、森林/水域覆盖层、必要道路权限、服务连接及完整部署验收；不能直接注入生产执行器。

## 已发现、需用户决定的问题

总册“地形、坡度与通行规则”4.3要求：桥面按自身真实高度、纵横坡及连接关系计算；桥头有合法坡道及层连接，不能直接跳上桥。5.1另要求完整扫掠占地合法。

本次从冻结地图 `routes/Asphalt` 真实三角面检查每座桥起终节点之间的中央8米宽矩形。8米是保障车的净宽要求；**中央条带检查并不等于完整桥梁/转弯路线验收**。三条条带面积均5600平方米、投影覆盖完整，但与道路相接处存在不同高度的共边，未能通过连续支撑检查：

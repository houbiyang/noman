# 手动对战操作说明

本模式在原项目沙盘中编排与播放，每轮推进60仿真秒，最多60轮。使用现地图已验证区域；未验证地表与不连续桥头仍关闭，不能将本地手动模式视作全地图竞技验收。现地图模型和规则精度不变。

## 赛前部署与开战

1. 新局进入沙盘后，上方持续显示“部署阶段”。若页面恢复的是已有对局，点击左下角“战斗”→“部署新对局”，开始新的本地部署草稿，原对局记录保留。
2. 选择蓝方或红方，点击“部署本方兵营”（或右下角“军队”）。每方必须放置侦察、地面、保障三座兵营。
3. 每座兵营点击“在沙盘选址部署”，再点击本方已核验部署区域。可先“定位参考位置”，也可主动“选择参考位置部署”。后端检查兵营、服务面和出兵区；非法位置会提示并保留原部署。
4. 逐营设定本局单位总数，再点击“生成本局…个单位”。每类0～10个、每方合计至少1个；零单位兵种仍须部署兵营并确认生成0个。单位在兵营邻近合法出兵区生成，无人机初始停靠。
5. 点击“确认本方部署完成”，切换另一方重复以上操作。双方确认后才能开始；任一方修改数量或位置都会取消双方就绪，需要重新确认。部署草稿保存在当前浏览器，刷新后恢复。
6. 点击左下角“战斗”→“本地手动测试”→“对战开始”。后端完整验收双方部署并创建对局，将兵营、编制及数量锁定。此时进入第1轮指令阶段，尚未推进仿真时间。

“手动配置”入口已由“对战开始”取代。战中不能新增单位、更改编制或重放兵营；伤亡和资源变化仍由规则裁决。单个兵营预览通过后，全体部署仍需在开战时检查相互重叠等条件。AI接口异常不影响本地手动模式，但数据库或部署验收失败不能跳过。

## 每轮怎么操作

1. 完成上述部署并开始对战后，切到蓝方视角，点击本方单位，在下方控制面板编排指令。
2. 指令先暂存到本方草稿。完成后锁定本轮。需要修改时，应在锁定前完成；锁定失败按提示修正后再提交。停靠无人机移动、非法飞行路线等静态错误会在锁定前提示。
3. 切到红方视角，编排并锁定红方指令。某一方不需要新指令时，可以直接锁定，已有持续任务照常执行。
4. 切到主持人视角，结算本轮。等待后端完成60秒裁决与保存，再在原沙盘观看本轮结果。本机实际路线单轮结算最长约31秒墙钟时间，等待期间不要重复点击结算。
5. 退出播放，查看最新单位和据点标签，再开始下一轮。播放过程中不能下令；播放、暂停或拖动进度不会扣除资源或再次结算。

“暂存”不会立即移动、开火或补给。“停止移动”仅停止移动通道；“取消任务”取消攻击、侦察、服务等任务通道。需要同时停止两者时使用“停止并取消任务”。未发新指令时，已有持续移动和任务沿用，不能将空草稿理解成停止。

## 指令作用与限制

| 单位／入口 | 指令 | 操作及作用 |
| --- | --- | --- |
| 本方各单位 | 移动到、坐标路线 | 设置目的地，可包含最多7个途经点；不自动寻路。途中重新下令会替换移动路线。 |
| 本方各单位 | 停止移动 | 下一轮停止移动；持续攻击／服务等任务需单独取消。 |
| 本方各单位 | 取消任务 | 下一轮取消任务；持续移动不受此按钮影响。 |
| 本方各单位 | 停止并取消任务 | 同时暂存停止移动与取消任务。 |
| 履带地面单位 | 攻击目标 | 从本方当前可见敌方单位中选择；实际观察、射线、射程、弹药和能源由后端裁决。不会自动追击。 |
| 履带地面单位 | 范围攻击 | 指定区域授权，在规则允许的合法目标中裁决；不是对任意地图位置无条件造成伤害。 |
| 侦察无人机 | 侦察目标、侦察位置 | 设置侦察任务；能否获得情报取决于实际观察条件。 |
| 侦察无人机 | 起飞、降落 | 按规则执行起降；持续移动必须先停止，停靠状态不能直接飞行移动。 |
| 保障单位 | 补充／修复单位 | 选择同方目标，选择能源、弹药或修复耐久；可按累计补充数量或目标余额服务。 |
| 保障单位 → 悬停无人机 | 补充能源 | 仅能源，水平距离不超过100米，并满足静止、库存及速率限制。空中弹药、修复、兵营服务不开放。 |
| 本方各单位 | 兵营补充 | 指定本方合法兵营与资源目标；检查实际距离、单位状态和库存。不会自动移动到兵营。 |
| 主持人 | 结算本轮 | 仅在红蓝双方锁定后推进一次60秒并持久保存记录。 |
| 主持人 | 单轮／从头播放 | 在原沙盘观看某轮，或从首轮连续播放到最新已结算轮；可暂停、拖动、切换0.5／1／2／4倍速、定位历史单位或最近事件并退出。 |

补给／修复双方需保持符合规则的静止状态。补给尚未完成时会延续到下一轮；离开合法范围、资源不足等情况以真实裁决为准。占点不需要独立“占领”按钮：将合格单位移入有效范围后驻留，由后端根据完整占地、争夺和持续时间自动判定。

## 输入精确路线

“坐标路线”使用业务坐标，X范围0～120，Y范围0～80。换算为地图米制：X米＝业务X×100，Z米＝业务Y×150。每行输入一对 `X,Y`，最后一行是终点，前面的行是途经点。范围校验通过不代表地表一定可通行。

蓝B-G01当前推荐新部署到P-03的四批已验证路线，见[有序导航路线](本地手动演示_有序导航路线_2026-11-17.md)。必须等上一批持续移动完成再发送下一批；不能机械地每轮换一批。若单位受阻仍保留移动，应检查状态并修改路线或使用“停止并取消任务”。

此坐标路线只适用于相同冻结地图和指定新部署，不适用于旧蓝部署 `(10850,8100)m`。界面点击也可以移动，但像素选点不能保证与精确路线逐毫米相同。

## 结果怎么看

主持人可查看真实轮末资源、据点归属和回放；红蓝方只看各自权限内的信息。敌军未被观察时，不会因为切换操作面板而公开位置或资源。当前速度和基础速度不同：静止时当前速度为0，基础移速表示兵种标准值。

播放中的标签与当前播放时刻对应；退出播放后恢复最新战局。“上一事件／下一事件”用于跳转到已记录的动作，“定位最近事件”调整镜头到事件位置，“全图”恢复整体观察。攻击与补给效果取自已记录事件，视觉效果不会重新裁决命中或改变库存。

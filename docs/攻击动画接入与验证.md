# 3D 攻击动画接入

将「制作战斗协同与对抗演示动画」对话中的 **cannon-3d / 履带炮击三维预演**接入当前沙盘单位攻击，不是二维俯视预演，也不是新增独立演示网页。

## 表现

- 使用预演原履带模型的 `TurretYaw → GunPitch → GunRecoil → Muzzle` 骨架及网格，保留既有阵营材质。
- 炮塔水平瞄准、炮管对空俯仰、后坐复位、炮口焰与烟。
- 明亮弹头、渐细拖尾、已飞行路径余辉、命中闪光与火花、受击扰动。
- 地面车辆变暗、燃烧/烟；无人机旋翼减速并旋转坠落。坠落只移动模型，不改后端位置。
- 保留现有相机操作、地图、设置和单位面板；不导入预演的时间线、相机、假伤害或独立场景。

## 权威事件

`backend/unit_interactions.py` 在合法攻击已经扣弹、同批伤害已经结算后，将以下字段写入原有 JSONB 快照事件列表：

- `event_id`：持久唯一 ID；命令重试读取原提交结果，不再开火。
- `at`：仿真秒。
- `source / target`：单位、生命实例、兵种、阵营、开火当时的业务坐标、停靠状态。
- `amount / hp_after / ammo_after / lethal`：本次伤害、该轮同时伤害结算后耐久、射手剩余弹药、击毁标记。
- 内部 `audience`：开火时双方端点均为该席位合法已知的角色列表；此字段不下发。

`GET /games/{id}/view` 新增 `attack_events`，仅公开该席位在事件发生时有资格看到的事件，不带库存、命令或内部观察列表。事件只保留冻结的历史坐标，不再查询隐藏敌方当前位置。来源不可见时保守地不展示完整炮击，宁可少特效，也不从弹道泄露敌情。旧事件缺少身份/权限证据则不下发。

特效不调用攻击命令、不做碰撞判伤、不修改 HP、弹药、能源。野外保障与兵营恢复不会被误判为攻击。规则版本与伤害数值未改变。

## 回放与边界

- 沿用当前每分钟结算机制：已提交的移动轨迹先完成约 0.8 秒展示，随后以压缩间隔播放本次新攻击；同一仿真时刻的齐射同时播放。
- **这是结算后的表现回放，不是完整逐秒同步战斗时间线**。模型仍可见时从当前呈现的炮口/目标中心展示弹道；失视或已移除的对象仅使用事件冻结坐标，击毁可短暂显示见证过的残骸。
- HUD 始终显示本次提交后的最终权威资源，不会随动画再扣一遍；0.65 秒弹道延迟不改变规则命中时刻。
- 第一次连接只建立时间水位，不重播历史；重复刷新、切席位、切对局、分支读档和时间回退均不把旧事件当新攻击。
- 对象按 `unit_id + life_id` 匹配，旧生命的特效不能击中新生命。切换/清空投影立即隐藏旧角色全部弹迹及残骸。
- 仍不意味着完整 v1.1 战斗、复活、全规则几何及 AI 授权已验收。本轮不改变这些边界。

## 使用

在启用单位交互的对局中，由履带地面单位面板选择「攻击目标」，选择当前合法敌方目标并下达任务。双方准备完成、主持人正式开始后，推进一轮；满足可见、射程、冷却、能源/弹药等条件时，后端产生实际攻击事件并驱动动画。准备阶段下达按钮仍禁用，不擅自启动用户对局。

## 检查入口

- 后端：`python -m backend.portable test`，包含单位伤害/齐射、事件身份、结果、权限冻结、旧事件兼容、幂等提交及读档。
- Unity：`Qiongtu.Sandbox.Editor.SandboxAttackAnimationChecks.Run`，验证事件游标、模型骨架/材质、炮口后坐、特效生成、无碰撞/资源写入、切换清理；并运行原单位面板检查。
- 正式构建：`./unity-client/start-unity.command BuildWeb`。

资源来源：引用对话交付的 `cannon-3d/UnityPreview`，仅复制履带机械骨架 prefab、所需网格、Glow/Smoke 材质和着色器、球形特效网格；`SandboxCombatActor` 和 `SandboxAttackPlayback` 为正式适配，不含演示 fixture。

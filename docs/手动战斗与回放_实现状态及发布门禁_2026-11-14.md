# 手动战斗与逐轮回放：实现状态及发布门禁

日期：2026-11-14。此文是开发状态与验收清单，**不是总册替代品，也不是完整战斗功能已可玩的发布声明**。

## 1. 已确认边界

- 以《青岚_游戏规则总册_分类目录完整版_v1.1》为准；用户确认对外60仿真秒/轮，最多60轮，内部5秒计算不作为操作步骤展示，可提前终局。
- 蓝红独立暂存与锁定，主持人统一结算。战中模式冻结；手动测试免正式首缓冲/恢复门槛，不将此豁免带进正式agent模式。
- 每方每类0～10，每方至少1，总量不超过60，可不对称；只允许独立新局，禁止迁移旧局。
- 沿用P-01～P-05结构，不更换CAPTURE候选点。当前场景为`draft_not_playable`，不能把结构通过当成地表、路径、桥坡、服务面已验收。
- 两个预演仅复用3D模型、炮塔/后坐/受击/退场姿态和补给连接束/流动粒子。**不接入其自动选敌、靠近、起降、补给、到达扣血或裁决时间线**。

## 4. 权限、风险与失败处理

| 风险/级别 | 触发与影响 | 处理/日志 |
|---|---|---|
| P0 旧裁决冒充总册 | 新模式落回旧advance/交互，错误扣资源/计分 | 屏障拒绝旧命令；生产executor=None；engine_ready/can_resolve为false；新UI禁止锁定开战 |
| P0 回放推进战局 | 播放时调用命令或ApplyProjection | 纯游标不持有ServerClient；回放网络只有GET；独立模型/相机；重复播放前后比较命令/快照/事件数量 |
| P1 越权/信息串席 | 蓝红读主持人全量动画、跨局或过时回调 | 服务端host守卫；跨局404隐藏存在性；前端代次+局+分支绑定，切角色清空 |
| P1 草稿冲突/重复提交 | 起降与move冲突、并发重试 | 422 `INTENT_CONFLICT`保留原草稿；幂等键+原正文复核，不能新键盲目重发 |
| P1 回放篡改/漏轮/换生命 | 整轮hash、前驱或真实世界不一致 | `REPLAY_HASH_MISMATCH`/`REPLAY_CHAIN_INVALID`/`REPLAY_PREFIX_INVALID`等拒绝；停止加载，不补造缺帧 |
| P1 迁移误操作用户库 | 测试入口先prepare、目标名错误 | 仅随机测试库白名单；先备份和恢复验证；未上线前不运行portable prepare/test |
| P2 VFX长播分配 | 每帧创建/销毁特效 | 使用池；重复采样检验池大小不增长；不保留跨seek的未来炮塔姿态 |
| P2 网络超时/部分加载 | 只收到若干轮 | 暂停并丢弃失败加载，不显示旧动画冒充新轮；提示只读失败可重试，不补偿/重发战斗命令 |

API错误仅记录公开错误码、请求键、命令类型、对局/分支/快照关联、轮次与摘要。禁止输出席位令牌、DB密码、私有草稿正文、原始AI密钥或未授权敌方信息。检查`BATTLE_ENGINE_NOT_READY`、`INTENT_CONFLICT`、`REPLAY_*`及幂等收据，不把503误判为可切回旧引擎。

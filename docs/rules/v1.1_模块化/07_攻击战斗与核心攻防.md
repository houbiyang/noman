## 9. 攻击、弹药与目标选择

### 9.1 地面武器

| 项目 | 参数 |
| --- | ---: |
| 攻击间隔 | 10仿真秒 |
| 每次攻击消耗 | 1武器弹药 |
| 对地面／空中单位伤害 | 16 |
| 对核心伤害 | 10 |
| 对地面单位射程 | 600米 |
| 对空中单位射程 | 800米 |
| 对核心射程 | 600米 |
| 移动射击伤害倍率 | 0.6，即9.6／6 |
| 移动射击当步移动能耗倍率 | 1.25 |

无友军伤害、溅射、穿透、掩体减伤和随机命中。单位不阻挡子弹；兵营不挡视线／射线。合法确定性攻击只伤害所选目标，超量伤害不转移到下一目标。

每次射击须满足：已获任务授权、当前可见、距离、射击线路、存活、有正能源、弹药、冷却及目标可受攻击。取消的不合法攻击不消耗弹药或刷新冷却。首次冷却就绪，可在第一步合法攻击时开火；此后按实际开火边界加10秒（D-08）。

实际位移大于0才使用移动伤害倍率；单纯持有移动任务但本步完全等待，不自动减伤。移动射击能源先按可能开火预留1.25倍预算；最终没有开火则只结算基础移动能耗，不追加移动距离；不能先花光能源再追补开火成本（D-08）。

双方攻击意图在伤害提交前统一冻结，同步结算，允许互相击毁。受到非致命伤害本身不取消已合法的攻击；接受服务的单位本步不能攻击。

### 9.2 授权范围与默认选敌

- 普通已授权交战范围内，可按“最近合法当前可见目标，等距优先剩余耐久低者”执行，也可使用AI明确的集火／分火策略。
- 彻底同距同耐久以规则包冻结的轮换次序处理，不按红蓝循环顺序（D-04）。
- 失视立即停止针对该目标的精确射击；不得向历史坐标继续精确命中。
- 只可在AI授权范围内改选当前可见合法目标；不能因新观察擅自追击或创造新战略任务。
- 失视不创造新的追击路线；原有合法路线是否继续取决于已授权任务。进攻核心和缺弹的专用暂停规则优先。

## 10. 核心保护、攻击与防御

### 10.1 攻击解锁

1. **己方至少拥有4个有效、未被争夺的据点**，才可攻击敌方核心。
2. 据点无需己方驻军，但须为己方归属，且统一快照`S_point`无合格敌军压制；与收入压制完全同一口径（D-07）。
3. 核心资格在移动后、伤害前根据已有归属和现场状态统一检查；第4点本步结束才完成占领，则下一步才能提供解锁。
4. 第4点被敌军争夺／压制，本步核心即恢复保护；本步随后杀死争夺者不能追溯解锁。
5. 每次核心射击仍独立检查当前可见、600米射程、线路、能源、弹药和冷却。
6. 必须有AI明确的核心攻击授权；普通自动选敌不能擅自把核心列为目标。
7. 不采用旧3点解锁、120秒启动、180秒窗口或其他保护倒计时。
8. 已造成核心伤害不因重新保护而恢复。

### 10.2 防御

核心观察900米；自动防御射程900米，每5秒最多攻击一个合法可见目标，伤害8，可对空／对地，无弹药库存消耗。

目标优先级：最近合法当前可见敌人，其次剩余耐久低者，再按冻结轮换次序。不能攻击保护中的复活单位。核心受保护不影响防御；只有耐久归零并在本步统一结算后才退出后续步骤。

核心与地面单位的本步合法伤害同步提交，允许核心被摧毁的同一步仍完成其已合法形成的防御攻击。

### 10.3 攻击受阻默认行为

- **核心恢复保护：** 停止对核心射击，并暂停该进攻任务的接近移动；在合法非重叠位置等待、保留原任务并报告。不自动撤退或改为攻点。条件恢复后在后续步骤重新校验恢复原任务。
- **弹药耗尽：** 停止射击并暂停该攻击任务接近移动；合法等待、保留任务、报告。不自动返营、不自行寻找保障车。
- 有明确AI条件指令时，按合法预设分支执行；不能用默认等待覆盖既有合法撤退指令。
- “停止前进”不要求立即冻结在非法重叠处，须按安全停车处理；也不赋予无敌，仍可能被核心或敌军攻击。
- 核心保护在移动后才检查：若本步因争夺而首次恢复保护，本步已经提交的合法移动不回滚，立即取消本步核心射击，并暂停后续接近。若步初已经知道条件不满足，则先暂停移动（D-09）。

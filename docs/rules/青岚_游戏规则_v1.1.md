## 1. 对局目标与胜负

### 1.1 双通路胜利

1. 双方均以“据点持续收入＋击毁敌方单位得分”累计胜利分，先在结算边界达到 **1500分**的一方可获胜。
2. 当满足核心攻击条件时，可攻击敌方固定主核心；**敌方核心耐久归零直接获胜**。
3. 最长 **60仿真分钟**。到时未发生核心胜利，比较当步结算后的总分；高者胜，相同平局，无加时。
4. 没有“全军覆没”“弹药耗尽”“AI认输判断”“四角色任务完成”自动判负。能源与库存本身不是额外胜利分。

### 1.2 同一步结果优先级

1. 双方核心同时被摧毁：平局。
2. 只有一个核心被摧毁：摧毁敌方核心的一方胜，优先于本步纯积分胜利。
3. 核心均未毁：一方达到1500分则该方胜；双方均达到时比较步末总分，相同平局。
4. 均未达阈值但达到60分钟：比较步末总分，相同平局。
5. 先完整汇总同一步双方伤害与分数，再判胜，不按先遍历的阵营先结束。结束后不再生成下一步战斗、复活或得分。

## 2. 时间、控制与公平边界

### 2.1 权威时间与指挥机会

| 项目 | 规则 |
| --- | --- |
| 权威仿真步 | 固定5仿真秒，最长720步／60仿真分钟 |
| 普通规划边界 | 0、60、120……3540仿真秒；每边界双方共同一轮，终局后不规划 |
| 规划屏障 | 双方从同一权威时刻的各自合法视图规划；等待双方完成和校验后同时采用，快者不得提前执行或额外规划 |
| 整轮预算 | 每方120现实秒，角色、工具与一次格式修复共用预算；等待另一方不产生新轮 |
| 权威推进 | 采用后按5秒步计算至下一个60秒边界或提前终局；不受画面倍速驱动 |
| 战术控制 | 双方AI全自主；人仅可赛前配置和技术管理，开局后不得人工指挥 |
| 时间冻结 | 规划等待、缓冲背压、技术暂停均不推进战斗、移动、占领、资源、复活、保护或冷却；它们不是额外战术机会 |

普通规划不再采用“异步返回即生效／忙则跳过”的旧机制。同步屏障消除先返回先行动及因推理快慢错过规划轮的结构性差异；同模型、预算、工具权限、隔离、故障处理仍须验收，不能据此宣布所有计算公平问题已解决。

v1.1不启用天气、随机事件、随机故障、随机命中、暴击、经验、等级、科技和装备成长。没有未定义的隐藏加成。

### 2.2 已确认结果缓冲与连续演示

1. `T_authority`为已提交权威时间，`T_playback`为画面已播放时间，缓冲`B=T_authority-T_playback`，单位均为仿真秒。必须始终`0≤T_playback≤T_authority≤3600`。
2. 普通每轮对应60仿真秒、12个已提交执行步，不是一个单位的单条命令。开播前缓存3轮，即180仿真秒。若180秒前终局，已有结果直接开播，不等待凑满。
3. 正常目标领先画面2～3轮。只在规划边界且`B≤120`时可启动下一普通轮；初始填充同样遵守此门槛，每轮最多新增60秒，因此`B≤180`。缓冲满时等待消费，不额外推理，不消耗未启动轮的120秒预算。
4. 同一时刻最多有一组双方共同规划和一段权威推进；等待缓冲不得让任一方额外检索、重规划或预知下一快照。
5. 已提交执行步可逐步进入缓冲，不能展示计划预测、未提交伤害、未结算分数或占位动画充当事实。正常目标不是硬性最小缓冲，慢推理时允许低于120秒。
6. 播放自动速度按每个5仿真秒播放步起点的剩余缓冲选择；该播放步速度固定，消费一段已提交事实后重算。画面插值只表现已确认轨迹。

| 剩余已确认画面B | 自动播放速度 |
| --- | ---: |
| B≥120仿真秒 | 2倍 |
| 60≤B＜120仿真秒 | 1倍 |
| 0＜B＜60仿真秒 | 0.5倍 |
| B=0 | 0，停在最后已确认时刻并显示计算中 |

7. 缓冲耗尽后进入补缓冲状态，即使新来5／60秒也不立即反复开停；补足120秒后恢复，已权威终局则不等门槛，播放全部剩余结果。开播和恢复门槛只限制消费，不阻止合法生产。
8. 自动降速与恢复均记录；播放速度不改变任何权威参数、AI轮次、脱战计时或现实超时。正式基线不允许主持人用手动加速绕过本表；技术停播只能停止消费，不能加给一方指挥机会。
9. 理想全程2倍播放的60分钟战斗片段约30现实分钟，但还存在预缓存、推理、降速、加载和技术暂停；不承诺总时长30分钟或任意延迟下永不停顿。每轮60仿真秒若平均推理超过30现实秒，仅靠有限缓冲不能维持全程2倍。
10. 终局是权威事件；权威停止后只排空展示缓冲，界面到对应播放时刻才宣告胜负。不在权威终局后生成战斗、规划、得分或复活。

## 3. 开局与首次AI规划

1. 双方在各自允许范围完成赛前配置，部署草稿相互保密，不可通过界面窥视敌方兵营和单位。
2. 校验编制、兵营、预部署位置、地形、占地、规则／地图／可见性版本，锁定配置；不通过则不开局。
3. 每方20个单位直接处于合法预部署位置，资源满值；**初始单位没有出生保护**。
4. 权威保持0秒，根据合法观察源生成双方各自初始快照。双方同时启动首次规划，每方整轮120现实秒；先完成者等待，不行动或额外规划。
5. 双方均完成校验后在同一0秒边界采用；独立任务允许按第14节部分接受，不要求每条命令均合法。
6. 计算0～60秒结果，再从60秒各自合法视图共同规划下一段；同样计算至120、180秒。按第2节控制生产与开播，不能先把三轮都用0秒旧快照推理出来。
7. 初次轮计作0秒轮，后续正常轮仅在60秒网格边界，不因现实等待增加轮数。首次失败走统一技术恢复，不让另一方先开战。

## 4. 双方固定编制与基础参数

每方 **20个固定单位槽位：4侦察无人机＋12地面作战单位＋4保障车**。双方数量、类型、能力、资源上限与复活规则完全相同。

| 参数 | 侦察无人机 | 地面作战单位 | 保障车 |
| --- | ---: | ---: | ---: |
| 数量 | 4 | 12 | 4 |
| 耐久上限 | 40 | 100 | 80 |
| 自身能源上限 | 100 | 100 | 100 |
| 速度（米／仿真分钟） | 800 | 400 | 300 |
| 5秒最大基础移动量（米） | 200/3 | 100/3 | 25 |
| 基础移动能耗／公里 | 5 | 8 | 10 |
| 基础观察范围（米） | 1400 | 900 | 700 |
| 武器弹药上限 | 无 | 60 | 无 |
| 可攻击 | 否 | 是 | 否 |
| 可占领／争夺据点 | 否 | 是 | 是 |
| 编纂默认占地半径（米） | 停靠时2 | 2 | 3 |

无人机在飞行状态额外消耗 **2能源／仿真分钟**，悬停同样消耗，飞行移动能耗另加；合法停靠时不扣飞行维持能源（D-02）。保障车自身能源与服务库存分离：开车不扣服务能源库存。

保障车满库存：**能源200、弹药120、维修材料100**。维修1耐久消耗1维修材料。保障车没有可射击武器，“弹药库存”不是自己的武器弹药。

不增加新单位槽、不购买额外部队、不叠加升级；复活填回原槽位，不形成新军队。

## 5. 部署、兵营与核心建筑

### 5.1 部署区域保持现状

地图使用米制 `x,z`，高程为 `y`，范围12000×12000米。

| 阵营 | x范围 | z范围 | 矩形面积 |
| --- | --- | --- | ---: |
| 红方 | 1000～1900 | 3200～10400 | 6,480,000平方米 |
| 蓝方 | 10000～11200 | 1600～8800 | 8,640,000平方米 |

完整单位／兵营占地必须合法，不能只检查中心。双方可以在各自部署区内合法自由预部署，不得进入据点有效区域。**不缩小蓝方可用区域来暗中制造对称。** 区域面积不同是已知公平性风险，不据此直接断言一方胜率。

### 5.2 兵营

- 每方保留三类兵营，各类一座；赛前可在本方部署区合法选址，开局后固定，不能增建、迁移或占领敌营。
- 可建在合法非道路地面，不要求贴近道路；旧“距道路节点不能超过某数值”的测试限制不继承。
- 完整占地不能碰水、实体建筑、其他兵营、固定核心或非法坡面；不能堵住道路、桥头与必要通路。
- 默认兵营占地60×60米，边界、出口及服务锚点随地图包冻结（D-03），不是将当前显示模型大小直接当规则占地。
- **兵营不可被攻击、摧毁或功能性压制。** 敌军可占住合法出口空间或道路，造成实际出兵／通行受阻，但不改变兵营功能状态。
- **兵营实体占地阻挡移动与停车，但不阻挡观察和射击，不提供掩体。** 普通地图建筑仍正常遮挡。
- 没有仓库、机场或装饰性设施的免费补给；只有明确列入本稿的兵营与保障服务有效。

### 5.3 固定核心

核心独立于兵营，由地图固定，玩家不能选址。双方各一座、耐久1500；不可维修或自行恢复。核心位置公开；完整实体占地、接近点、观察锚点与攻击目标点必须由正式地图包提供。

**本次未批准核心坐标。旧 RED_CAMP／BLUE_CAMP 不能自动改名当核心。**

## 6. 移动、道路与地形

### 6.1 通行范围

1. 本方部署区内，本方地面单位可在合法地面自由移动，包括预部署、复活、返回及重新定位单位；道路与合法空地使用相同基础速度和每公里能耗。
2. 使用完整合法路线的最短旅行时间；旅行时间相同时优先道路，不强制先绕去找路。
3. 离开本方部署区后，地面单位只能走合法道路、桥梁及经核验的生成／任务／服务接入段，不能自动生成任意越野捷径。道路不按阵营专有，默认双方均可双向使用；敌军实体占用会阻挡通行，不等于道路改为某方专属单行道。
4. 敌方部署区不是本方的自由越野区。返营路线也不能穿过树林、水域、墙或不可通行坡面。
5. 地面不能穿越道路外树林；**树林中的合法道路可以通过**。合法林间道路不能因此被当作任意林间越野许可。
6. 桥面与桥下分层；道路二维交叉不等于路口，跨层必须有明确合法连接。
7. 无人机走合法二维航线，不受地面道路约束；地面建筑不自动禁飞，但正式地图必须提供空域通行政策，不能穿越未定义的飞行禁区。
8. 不继承旧快速、倒车倍率或坡度减速表。v1.1 仅采用上述基础速度；不可通行坡面由静态地图核验标记（D-03）。

### 6.2 友军与敌军占用

- **友军移动中可不限数量、类型、方向相互穿过，包括桥梁，不因友军通行而排队或退让。**
- 友军停止时不能重叠：包括停火射击、等待、补给、停靠与实际生成。移动射击仍算移动。
- 非保护状态的敌方地面单位保留实体阻挡，不能穿透或无空间交换位置。复活保护中的单位采用第12节穿行例外：不阻敌军移动，但不能重叠停车或非法解除。无人机之间不做空中碰撞；停靠位置仍须分配（D-04）。
- 残骸仅视觉表现，不阻挡、不遮挡、不减伤。
- 一步内按完整扫掠轨迹检查普通敌方接触；保护穿行例外仍检查静态几何、能源与合法边界位置。必须统一求解，不能用数组先后制造优先权。

### 6.3 目标停车与冲突

1. 系统可在指令目的地50米内分配合法停车点，且必须仍满足原任务的占领范围、射程、线路、服务距离与导航层。
2. 去停车点使用真实路线、时间与能源，不免费移动50米。
3. 无停车位时，沿原路线在可达合法位置等待；停车位释放且原任务仍合法时可继续，不能自动换战略目标。
4. 停车位竞争按连续等待时长优先；完全相同按仿真步交替阵营优先、阵营内部轮换。等待计数不能由刷新、重复发同任务重置获益（D-04）。
5. 普通敌军迎面接触：双方在接触前停下，不应用轮换把一方推过另一方。保护穿行依第12节处理。已存在合法占用不因轮换被驱逐。
6. 移动前预留该步必要的合法停止位置；若能源不足以移动到下一安全停止点，应提前停在合法位置，可以剩少量能源，只扣实际行驶消耗。
7. 不能先批准穿入友军，再因能源不足停在友军体内；无法证明可安全停止的轨迹不得执行。战损形成视觉残骸，不额外产生停车实体。
8. 不因等待积攒下一步移动距离，不瞬移、不推挤、不无成本自动返营。通路不通可报告受阻，绕行须在已授权任务范围内合法寻路。
9. 安全停车约束优先于执行会造成非法停止的轨迹；这不是按友军数量或兵种增加道路排队规则。保护单位的边界非重叠检查属于联合轨迹校验，不能到期后临时延长无敌或把单位挪走。

## 7. 观察、树林与信息边界

### 7.1 观察与射击分开

所有有效观察源每5秒更新，本方即时共享；射手仍独立检查自己的射程和射击线路。初始0秒也计算合法观察。失视后保留最后发现记录和时间戳，不实时更新隐藏位置、耐久、弹药或行动。

规则采用简化高度判定：固定建筑阻挡体、地形三角面、桥面分层，不直接取渲染模型／帧率／摄像机。观察和直射引用同一实体遮挡目录，分别从各自起点检查。v1.1 不启用弹道抛射、透射、楼层驻扎和高地射程加成。

技术默认：范围用水平中心距；规则观察、射击与目标判定点均为所属支撑表面上方2米，无人机也不使用画面48米高度。建筑使用版本化有向占地和高度，地形按已存在的三角插值规则，射线对规则三角面／阻挡体作完整相交检查，不以稀疏采样漏过山脊；非目标实体相切按遮挡处理。源和目标自身实体不自挡，其他普通建筑正常挡；几何容差0.01米仅消除数值误差，不放大射程或占点圈（D-05）。桥面遮挡厚度等必要几何缺失必须阻止该场景发布，不能按无厚度穿射。

### 7.2 无人机树林规则

| 情况 | 距离条件 |
| --- | --- |
| 无人机在林外，目标在林外 | 基础1400米，另检查实体遮挡 |
| 无人机在林外，目标在林内 | 总距不超过1400米，且从射线进入目标所属林区的位置到目标不超过600米 |
| 无人机在树林内 | 观察范围1000米，不反复叠减400米 |
| 无人机在林内观察同林目标 | 使用1000米，不额外压成600米 |
| 无人机在林内观察林外目标 | 使用1000米 |
| 离开树林 | 恢复1400米 |

树林不阻挡子弹、不提供减伤；地面单位与保障车不因树林额外缩减900／700米视野，仍检查建筑和地形遮挡。

森林边界与多个林区的编纂默认见 D-06。没有森林几何不能把树木材质颜色当精确规则范围。

### 7.3 核心观察

- 核心自带900米观察，每5秒更新并共享给本方；保护期间仍有效。
- 建筑、山体正常遮挡；树林不额外缩减核心观察范围。
- 无己方单位驻守，核心也能发现无遮挡来敌；共享视野不能让核心穿墙射击。

### 7.4 公开与隐藏

公开：地图规则地形、道路、5个据点位置及归属／争夺状态、双方部署区、双方固定核心位置、总分、比赛时钟与终局结果。

仅本方完整可见：本方单位／兵营、资源、任务、等待状态、核心实时耐久、AI运行情况。

敌方兵营位置、初始和实时部队、敌方核心实时耐久须依赖合法观察。敌核心失视后只保留最后观察耐久及时间；核心毁灭与胜负全局公告。发现建筑不等于发现旁边部队或内部待复活单位。公众据点状态不得泄露敌方身份、数量、精确坐标。隐藏阻挡只回报“前方受阻／条件待核验”，不能凭碰撞回执透视。

展示时间边界：上述公开／私有划分适用于同一个逻辑时刻。AI只取权威时刻各自合法视图；比赛画面、HUD、单位详情、战报、得分曲线和终局通知只取播放时刻，不能混读领先2～3轮的权威状态。管理员技术通道单独鉴权；全局调试数据不得转入AI输入。播放不回写权威世界，回放不重新触发伤害、服务或计分。

## 8. 据点、占领与积分

### 8.1 布局

共5个等值、初始中立的据点：双方各2个上下分散的本岸近点＋1个中央桥头陆地点。中央只允许指定陆地表面参与占领，不允许桥面、河床、对岸重叠层凭平面距离占领。

半径 **250米** 为首测值，有效区域为圆盘与批准地表掩码的交集；空中单位不能占点。具体坐标尚未通过地图发布验收，见第17节。

### 8.2 资格、争夺与进度

1. 地面作战单位、保障车可占领与压制；无人机、能源0、耐久0、出生保护中的单位不合格。步初能源0者即使当步补能也不追补资格。
2. 中立点占领30秒；敌方点先中立化30秒，再占领30秒。人数不加速。
3. 移动后、伤害前，对每个点冻结合格双方在场集合`S_point`。收入压制、核心解锁和争夺清零共用该快照，不能一个查整步轨迹、另一个查终点。
4. 进度每步5秒。同一步至少一名本方合格单位**完整停止在有效区域且伤害后仍存活**才可增加；当步进入不能补算驻留，路过不贡献进度。持续合法停驻时可射击、服务或接受服务。
5. `S_point`双方都有合格单位，或当前占领阶段的对方在快照中有合格单位：该步争夺，保留原归属，当前未完成阶段清零。已完成中立化不回滚。对方在快照后同一步被击毁也不追溯取消争夺。
6. 若没有第5项争夺，但本阶段无完整停驻的合格存活单位，未完成进度清零；若中立点只有另一方的合格完整驻留者，可开始其新阶段。阶段方转换不继承敌方未完成进度。
7. 唯一占领者最后伤害结算死亡，不获本步进度，未完成阶段清零。单纯途中经过且不在`S_point`的敌军，不压制也不额外触发争夺清零。
8. 取得归属后离开仍保留，不要求驻军；当步结束取得的归属，下一步才可供收入和核心解锁使用。

### 8.3 收入与统一压制

每个己方据点每完整5秒 **1分**。该步归属必须稳定，且`S_point`无合格敌军。新占领在步末完成，下一完整步首次收入；如30秒完成、35秒首次得分。

敌军单独在原主无人点内，也会压制收入和该点对核心解锁的贡献；不要求双方驻军同时在场。移动中但快照时在点内的合格敌军可以压制，不等于能获得占领进度。

仅途中经过、快照时已离开，不压制；快照内的敌军随后同一步被击毁仍压制该步，下一步重查。能源0不压制，失能也不自动取消旧归属。D-07在本版以此替代v0.1的双口径。

### 8.4 击毁分

| 被击毁对象 | 得分 |
| --- | ---: |
| 敌方侦察无人机 | 5 |
| 敌方地面作战单位 | 10 |
| 敌方保障车 | 8 |

每次复活后再次被击毁仍给全额分，无衰减、无首次击毁奖金；本轮明确选择保留，围营刷分仍是待测风险，不写成已消除。单位或核心防御击毁敌军均计入本阵营。能源归零不是击毁，不给分。伤害只来自敌方合法攻击，残骸、超量伤害、重复回放不能重复加分。

## 9. 攻击、弹药与目标选择

### 9.1 地面武器

| 项目 | 参数 |
| --- | ---: |
| 攻击间隔 | 10仿真秒 |
| 每次攻击消耗 | 1武器弹药 |
| 对地面／空中单位伤害 | 16 |
| 对核心伤害 | 10 |
| 对地面单位射程 | 600米 |
| 对空中单位射程 | 800米 |
| 对核心射程 | 600米 |
| 移动射击伤害倍率 | 0.6，即9.6／6 |
| 移动射击当步移动能耗倍率 | 1.25 |

无友军伤害、溅射、穿透、掩体减伤和随机命中。单位不阻挡子弹；兵营不挡视线／射线。合法确定性攻击只伤害所选目标，超量伤害不转移到下一目标。

每次射击须满足：已获任务授权、当前可见、距离、射击线路、存活、有正能源、弹药、冷却及目标可受攻击。取消的不合法攻击不消耗弹药或刷新冷却。首次冷却就绪，可在第一步合法攻击时开火；此后按实际开火边界加10秒（D-08）。

实际位移大于0才使用移动伤害倍率；单纯持有移动任务但本步完全等待，不自动减伤。移动射击能源先按可能开火预留1.25倍预算；最终没有开火则只结算基础移动能耗，不追加移动距离；不能先花光能源再追补开火成本（D-08）。

双方攻击意图在伤害提交前统一冻结，同步结算，允许互相击毁。受到非致命伤害本身不取消已合法的攻击；接受服务的单位本步不能攻击。

### 9.2 授权范围与默认选敌

- 普通已授权交战范围内，可按“最近合法当前可见目标，等距优先剩余耐久低者”执行，也可使用AI明确的集火／分火策略。
- 彻底同距同耐久以规则包冻结的轮换次序处理，不按红蓝循环顺序（D-04）。
- 失视立即停止针对该目标的精确射击；不得向历史坐标继续精确命中。
- 只可在AI授权范围内改选当前可见合法目标；不能因新观察擅自追击或创造新战略任务。
- 失视不创造新的追击路线；原有合法路线是否继续取决于已授权任务。进攻核心和缺弹的专用暂停规则优先。

## 10. 核心保护、攻击与防御

### 10.1 攻击解锁

1. **己方至少拥有4个有效、未被争夺的据点**，才可攻击敌方核心。
2. 据点无需己方驻军，但须为己方归属，且统一快照`S_point`无合格敌军压制；与收入压制完全同一口径（D-07）。
3. 核心资格在移动后、伤害前根据已有归属和现场状态统一检查；第4点本步结束才完成占领，则下一步才能提供解锁。
4. 第4点被敌军争夺／压制，本步核心即恢复保护；本步随后杀死争夺者不能追溯解锁。
5. 每次核心射击仍独立检查当前可见、600米射程、线路、能源、弹药和冷却。
6. 必须有AI明确的核心攻击授权；普通自动选敌不能擅自把核心列为目标。
7. 不采用旧3点解锁、120秒启动、180秒窗口或其他保护倒计时。
8. 已造成核心伤害不因重新保护而恢复。

### 10.2 防御

核心观察900米；自动防御射程900米，每5秒最多攻击一个合法可见目标，伤害8，可对空／对地，无弹药库存消耗。

目标优先级：最近合法当前可见敌人，其次剩余耐久低者，再按冻结轮换次序。不能攻击保护中的复活单位。核心受保护不影响防御；只有耐久归零并在本步统一结算后才退出后续步骤。

核心与地面单位的本步合法伤害同步提交，允许核心被摧毁的同一步仍完成其已合法形成的防御攻击。

### 10.3 攻击受阻默认行为

- **核心恢复保护：** 停止对核心射击，并暂停该进攻任务的接近移动；在合法非重叠位置等待、保留原任务并报告。不自动撤退或改为攻点。条件恢复后在后续步骤重新校验恢复原任务。
- **弹药耗尽：** 停止射击并暂停该攻击任务接近移动；合法等待、保留任务、报告。不自动返营、不自行寻找保障车。
- 有明确AI条件指令时，按合法预设分支执行；不能用默认等待覆盖既有合法撤退指令。
- “停止前进”不要求立即冻结在非法重叠处，须按安全停车处理；也不赋予无敌，仍可能被核心或敌军攻击。
- 核心保护在移动后才检查：若本步因争夺而首次恢复保护，本步已经提交的合法移动不回滚，立即取消本步核心射击，并暂停后续接近。若步初已经知道条件不满足，则先暂停移动（D-09）。

## 11. 能源、失能与补给

### 11.1 能源归零

能源0是失能，不是被摧毁。不得移动、攻击、产生新观察、提供服务、占领或争夺；保留地面实体占地，可被攻击、可接受合法服务。

不自动死亡、复活、回收、返营或恢复。已取得据点归属不自动取消。区外搁浅依赖现场救援；若本来就在合法兵营服务位置，也可接受兵营服务。

本步补能到正数，最早下一步恢复行动、观察和占领资格；不能同一步先加油再移动／攻击。非零能源但不足下一安全行驶段时提前停车，不强制扣成0或把失能和低能量混为一谈。

### 11.2 野外保障车

- 供需双方本步完整停止、处于合法可达的同一服务地表，距离不超过100米；无人机须在合法停靠点，不允许隔空给飞行中的无人机补给。
- 每车每5秒服务 **1目标、1资源**：补2自身能源，或2武器弹药，或2耐久。
- 扣同量对应库存；维修材料按1:1。不能超出接收方上限，也不能库存负数。
- 同一接收方每步仅一个服务来源、一次服务，不叠加多车或兵营。
- 可给其他保障车补自身能源／耐久，不能野外自我服务；不能野外凭空恢复保障库存。
- 接受服务者本步不能移动或开火；保障提供者不能同时移动。合法完整驻留时仍可占点。
- 伤害先于服务。非致命命中不自动中断服务，致命伤害后不能被同一步维修救回；死者不能提供或接受服务。

### 11.3 兵营补充

本方三座兵营均可服务所有本方单位类型。距离服务锚点不超过100米，必须有合法到达和接触条件；隔墙、隔水、跨桥层不算可服务。兵营自身不挡射线不等于允许穿越其实体进行服务。

**兵营脱战门槛：** 在本步服务结算边界`u=t+5`，单位连续15仿真秒未开火且未受到实际正伤害，才能接受兵营任何补充。记录本生命`last_fired_at`与`last_damaged_at`，均按实际事件提交边界计；从未发生对应事件记为空，不虚构新生受伤。条件为每个非空时间戳均满足`u-last_event_at≥15`。

- 本步先伤害、后服务；本步实际受伤将时间戳更新为`u`，立即失去兵营服务资格，即使伤害非致命。被保护而拒绝的攻击、0实际伤害不刷新受伤时间。
- 5秒开火且此后未受伤，最早可在20秒结算接受服务，前提是15～20秒完整停止、预先申请且不射击。10秒的冷却空档不能补给。
- 本生命开火／受伤时间不因现实推理、停播、任务刷新或排队而清空；复活产生新生命并重置历史。仅在脱战不足时，不占实际服务名额，不凭排队绕过门槛。
- 对所有兵营补充项目和所有单位类型一致适用；不要求脱战后再驻留15秒。野外保障仍允许非致命受击后服务，不增加该门槛。

每座兵营每5秒最多服务 **4个单位**，同一单位不能占多座兵营名额；一个单位占一个名额，可同时补齐以下各项，但不超过容量：

| 每5秒补充项目 | 补充上限 |
| --- | ---: |
| 单位自身能源 | 50 |
| 单位武器弹药（如有） | 50 |
| 单位耐久 | 50 |
| 保障车能源库存 | **50** |
| 保障车弹药库存 | 60 |
| 保障车维修材料库存 | 50 |

保障车能源库存补充量采用最后修改的 **50，不是100**。兵营库存无限，但吞吐有限。保障车接受兵营服务时可同时恢复自身与库存，仅占1名额，不能同一步提供野外服务。

排队优先级由AI指定；同优先级按连续等待更久者先；仍同序按阵营内轮换。未指定视为相同默认优先级。全满、死亡、离开范围者退出；离开后重新进入不保留连续等待时长。队列不自动提升策略优先级，可能被高优先级任务长期压后，须记录（D-10）。

服务意图在伤害前锁定：本步计划接受服务者不同时开火，即使随后因受伤而失去兵营资格，或野外服务源被击毁，也不追溯补发攻击。伤害后按脱战与其他资格过滤，再分配名额；可递补预先申请且完整停止的候选，不能事后把已开火者改成接收者（D-10）。

## 12. 死亡、复活与保护

1. 耐久降到0即被击毁，一次死亡只记一次击毁分，撤销原活动任务和待执行队列。
2. 等待时间在死亡时按当局仿真时间锁定：

| 死亡时间 | 等待 |
| --- | ---: |
| 小于20分钟 | 60秒 |
| 20分钟及之后、小于40分钟 | 90秒 |
| 40分钟及之后 | 120秒 |

3. 免费复活至原固定槽位，满耐久、能源、武器弹药及保障库存；新生命实例必须有不同标识以防旧命令／伤害误用。
4. 首选对应类型兵营出口；占用时可选同一方本部署／主生成区内其他合法兵营出口。不能借此在地图其他地点复活。
5. 出口全部无合法非重叠位置时，在兵营内离图等待；不重启倒计时、不产生视野、不占点、不攻击、不阻挡、不消耗保护时间。

## 14. AI任务、共同采用与技术暂停

### 14.1 权限与任务

每方总指挥、侦察、陆兵、保障角色只读本方权威时刻允许信息，输出结构化任务。执行器处理合法动作，不创造战略目标、分数或能力。

AI可预设撤退条件、路线、补给安排、交战范围和依赖；执行器每5秒检查。没有有效任务则待命，不以固定脚本伪装规划成功。本版不增加复活默认预案。

### 14.2 同步规划与部分接受

1. 0、60……3540秒边界且未终局时，按第2节背压启动双方同轮规划；相同权威时刻不代表双方拿到相同敌情，必须各自裁剪视图。
2. 输入绑定分支、规则／地图／可见性版本、权威快照、轮次与单位生命标识。规划期间权威状态冻结；播放可继续消费旧结果，但不反向改变输入。
3. 双方均返回并校验完才共同采用；先返回者不能执行、重新看播放结果或增加推理。到下一60秒边界前不启动另一普通轮。
4. 独立合法任务采用，非法及其依赖拒绝；未修改单位保留仍合法旧任务，否则待命。共同采用不等于因一条错令清空全队。
5. 回执不能泄漏隐藏敌情；猜测不构成可执行情报。待采用结果不得被模型、对方或比赛画面预览。

### 14.3 整轮超时与修复

**每方120现实秒是整轮从启动到完整方案返回的总预算**，包含指挥／兵种角色、工具和格式修复，不按角色、重试或请求重置，不受播放速度影响。完整合法可解析结果恰在120秒返回可接受，超过则超时；后续确定性校验不得被当作延长模型推理的通道。

格式无法解析只允许1次修复，用原冻结输入且包含在剩余预算。格式正确但有非法任务走部分接受，不无限重试。任一方超时或修复后不可用，废弃该未采用的双方轮次，进入全局技术暂停；不得先执行成功一方。

### 14.4 故障恢复与播放

1. 保持最后已提交权威状态，不回滚移动、伤害或分数。双方在途／未采用方案失效，迟到结果仅日志。
2. 管理员仅技术排障，不给战术命令、不单边更换模型／提示词／预算。显式启动双方恢复轮，各自从暂停时刻合法视图规划，新的120现实秒。
3. 双方完成后同边界共同采用。每次故障最多2轮恢复；仍失败保持暂停，放弃记技术中止、不计竞技胜负。
4. 恢复轮覆盖当前边界待采用的轮次，不在同一边界再启动普通轮；若暂停位于非60秒边界，可恢复后执行至下个正常网格，不能追补历史轮。
5. 人为技术暂停同样废弃双方未采用结果并共同恢复，不能改名重置故障次数。单纯缓冲背压／开播等待不属于故障，不触发额外恢复轮。
6. 已确认播放结果可继续消费至权威暂停处，再显示等待；管理员故障通知可立即显示但不得包含未播放战斗情报。技术中止则停止竞技结果输出并保留已有轨迹，不把暂时领先宣布为胜者。
7. 保存／恢复按提交号幂等；旧分支／生命／轮次不能写当前对局，不因离线现实时间补算仿真。播放进度独立保存，不反推权威状态。

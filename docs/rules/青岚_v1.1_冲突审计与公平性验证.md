## 2. 主要冲突与处理决定

### A-01　异步推理导致指挥机会不等【设计已修订，集成待验】

**旧反例：** 仿真在模型推理时继续，以2倍播放；普通请求每60仿真秒、忙则跳过，返回即生效。排除0秒初始方案，考察前600仿真秒：

| 每次模型现实延迟 | 对应仿真延迟 | 截至600秒完成的后续方案 |
| ---: | ---: | ---: |
| 10秒 | 20秒 | 9 |
| 60秒 | 120秒 | 4 |
| 120秒 | 240秒 | 2 |

这不是推断模型智力差异，而是时间制度本身给了不同机会。该反例模型仅描述旧异步规则，不代表现行后端已经按此运行。

**v1.1：** 每60仿真秒共同规划，双方输入来自同权威时刻各自合法视图；权威等待，双方完成后同时采用。先返回者既不能先动，也不能重规划。每方整轮120现实秒含角色、工具和格式修复，不因重试重置；恰120秒返回可接收，超过则双边未采用轮失效、全局技术暂停。

**参考结果：** 10／60／120秒的9种红蓝组合及互换，共同采用边界不变；10轮参考推进中双方均得到10次采用。这里10轮包含0秒轮，不能拿它与上表“排除0秒”的数量作未经对齐的直接增幅比较。120与120.001秒边界、修复耗时合并、未采用不推进也已检查。

**未验证：** 实际供应商超时、工具并发隔离、模型质量差异、人工排障串入战术信息、两轮恢复的真实状态机。

### A-02　公平推理与连续播放耦合【设计已修订，前端／服务待验】

旧的“维持2倍画面同时让推理等待不影响对抗”不能只靠一个时钟满足。v1.1分别定义权威时间、播放时间和缓冲 `B=T_authority-T_playback`。

- 顺序规划并缓存3轮、180仿真秒开播，每轮必须读取该轮新权威快照，不能三轮共用0秒视图。
- 下一普通轮仅在 `B≤120` 启动，每段最多60秒，生产上限180秒；满缓冲不额外启动规划或工具。
- 速度为 `B≥120 → 2倍`，`60≤B<120 → 1倍`，`0<B<60 → 0.5倍`，`B=0 → 停止`。
- 耗尽后补足120秒恢复；补60秒不恢复。若已终局，不等180秒预缓存或120秒恢复门槛，排空剩余结果。
- HUD、详情、资源、比分、战报、导出和终局提示都按播放时间投影；不能只让地图滞后而让分数或通知泄露未来。
- 规划、背压与技术暂停冻结权威；播放调速只消费已提交事实，不产生战斗结果或重做计分。

**D-14编纂细化：** 档位在每个5仿真秒播放步起点选定，本步固定，下一步重算。例：B=120时本步2倍，播5秒耗2.5现实秒；若无生产，下一步B=115改1倍。此为技术默认，不是新增战斗参数。

**参考结果：** 预缓存、背压、档位边界、步内固定速度、耗尽补60／120、提前终局、禁止占位结果和投影过滤均通过。参考缓冲器以整段提交简化生产，**没有验证真实实现的逐5秒提交、线程时序或播放器插值**。

**保留限制：** 每轮60仿真秒若平均推理超过30现实秒，有限缓冲不可能维持全程2倍。不保证任意模型延迟下永不停顿，也不保证60仿真分钟的比赛总耗时恰30现实分钟。

### A-03　兵营可利用10秒射速间隙补满【设计已修订，整体平衡待测】

**旧最小反例：** 守军耐久100，在5、15、25……秒开火，10、20、30……秒请求兵营维修50；假定固定来袭火力也每10秒一轮，每名来袭者16伤害：

| 固定来袭单位数 | 简化旧结果 |
| ---: | --- |
| 3 | 每轮48，100→52→100；600秒内守军仍可完成60次开火 |
| 4 | 每轮64，维修抵不过长期损耗，35秒死亡 |
| 12 | 首轮192，5秒死亡，不能靠维修救回 |

这证明的是一个**特定补给循环**，不是基地绝对无敌。参考模型把来袭火力固定，不模拟攻击者损耗、瞄准、地形、补弹或完整作战。

**v1.1：** 兵营所有服务结算时，接受者须连续15仿真秒未实际开火、未受实际正伤害。本步伤害先结算，立即取消本步服务；致死不救回。5秒开火后10秒、15秒不能服务，最早20秒可服务，且15～20秒完整停止、提前申请、不射击。

- 使用本生命 `last_fired_at`、`last_damaged_at`；事件记提交边界，未发生记空。
- 现实等待、停播、刷新任务不增加脱战时间、不清空历史；复活是新生命。
- 每营每步仍最多4人；每接收者一来源。不合格者不占实际服务名额，可递补预先申请且完整停止者，不能伤害后临时改令补枪或补给。
- 六项补充量仍为 **50／50／50／50／60／50**，第4项保障车能源库存为50，**不是100**。
- 野外保障车服务不增加15秒脱战；非致死受伤仍可服务，完整停止、不同时开火和库存限制不变。

**参考结果：** 脱战边界、两种时间历史、本步正／零伤害、死亡、完整停止、数量／来源上限、新生命和六项补充量通过。固定来袭3人的同样射击节奏在新版不能间隙维修，参考反例25秒死亡；这仍不是实际对局预测。

**保留风险：** 兵营无限库存、50／5秒对比野外2／5秒仍有25倍单接收者速率差，且拥有多个服务名额。不得把“循环被阻断”扩写成“基地龟缩已解决”。

### A-04　据点边缘往返造成两套压制规则【设计已修订，运行待验】

旧规则收入看整步经过，核心资格看移动终点。构造单位在据点边界内外各5米处，每5秒往返，持续60秒：旧收入可被压制12步，而核心只被阻断6步；移动单位又不获得占领进度。

**v1.1：** 移动后、伤害前冻结合格在场 `S_point`，收入压制、核心资格和争夺清零使用同一快照。

| 场景 | v1.1结果 |
| --- | --- |
| 途中经过、快照已离开 | 不压制收入、不阻断核心贡献、不额外清零 |
| 移动进入、快照仍在 | 可以压制，但不能补算完整5秒占领 |
| 快照合格敌军同一步随后被毁 | 该步仍压制／争夺，下一步重查 |
| 本方唯一完整驻留者随后死亡 | 不增加占领进度，未完成阶段清零 |
| 能源0、保护单位、无人机 | 不进入合格压制集合 |
| 第4点本步末才占得 | 下一步才供收入及解锁使用 |

**参考结果：** 边缘往返的新收入压制与核心阻断均为6步；路过不清零、进入不补占领、快照后死亡不反改资格通过。快照集合按双方分别计算，合法共享不等于向AI公开隐藏单位身份。

**未验证：** 正式有效地表掩码、真实停车／桥梁分层，以及6步中立化＋6步占领的完整引擎链路。总稿V-15～V-18仍须运行验收。

### A-05　复活保护形成不可击毁路障【规则已修订，几何求解仍阻断发布】

**v1.1：** 保护单位不阻挡敌军穿行；普通非保护敌军仍实体阻挡。初始预部署不享保护；战中复活最多15仿真秒，原150米保护区和参与限制保留。

**D-15安全细化：** 保护地面单位与敌方地面单位移动中可临时相穿，但在每个5秒提交边界必须非重叠并保留安全余量。移动前联合验证真实路线、能源和安全停止点；不合法的轨迹应事先缩短／拒绝，不得先穿入再瞬移、推挤、延长保护或永久穿模。友军移动仍不限数量和种类互穿，停车仍分离。

**参考结果：** 一维直线示例中，敌军可跨过静止保护者，普通敌军不能扫掠互穿；终点重叠、预算不足、静态非法被拒绝，拒绝示例保持原合法位置。

**关键限制：** 该检查器不是二维停车分配器，不求解多单位联合轨迹、弯路、桥宽或连续时刻保护解除。每步边界安全条件也可能拒绝无法在该步完成穿越的轨迹；是否出现吞吐或调度不公，须用实际求解器检验。不能宣称保护路障的所有真实场景均已解决。无法保证自然到期合法解除时，G-04不通过，不允许现场增发无敌时间。

### A-06　复活单位没有任务，保护结束后暴露【明确保留】

复活清空旧生命任务，等待下一次合法AI指令，不新增自动撤离或复活预案。保护最多15秒，不能因待命延长。

- 旧异步反例：125秒出生、140秒保护结束、200秒方案采用，存在60秒无保护待命；200秒不是新版正常60秒网格，不能写成新版必然调度。
- 新版同步例：125秒出生、140秒保护结束、180秒下一正常边界，仍可有 **40仿真秒**无任务暴露。180秒规划时权威冻结，现实推理等待不再额外增加仿真暴露。
- 出口无空间导致实际未生成，与生成后待命不同；离图等待没有视野、实体、保护倒计时，也不能重启已完成复活等待。

这里修订的是时间制度，不是替玩家选择撤退策略。风险状态为**保留／待统计**，不是“已消除”。

### A-07　重复击毁可能成为围营主收益【明确保留】

每个新生命击毁仍全额无人机5、地面10、保障8，不衰减。整编制价值 `4×5+12×10+4×8=172` 分，9轮整编制为1548分，超过1500。

这只是激励与量级核算：**没有证明9轮整编制击毁在真实地图、时限、能源、弹药和出兵约束下可实现**。保护不阻路、同步规划、脱战补给均不能被写成“反复刷分已解决”。

首测必须统计每槽累计失分、复活短期死亡率、围营持续时间、击毁／据点分占比，之后再决定是否另立修订；本版不擅加衰减或免分期。

### A-08　旧坐标、几何诊断与现行执行器被误当新规则验收【继续阻断】

旧地图只有3个任务点，不等于新5点。旧营地不能直接改名核心，旧桥中点不能直接当桥头陆地点。有限探针未通过不是整张地图无解证明；某组平面到达相等也不是正式选点批准。

本轮只编纂规则和做只读参考检查，没有批准新点、没有重画道路／部署区，没有把旧执行器改成v1.1。详见第3、4节。

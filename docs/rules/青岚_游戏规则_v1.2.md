## 1. 对局目标与胜负

### 1.1 积分与固定兵力

1. 双方以据点持续收入及击毁敌方单位累计阵营总分，积分目标为**1500分**。
2. 最长**60仿真分钟**，无加时。兵营不是胜利目标，不可攻击或摧毁；本版不设置核心建筑、核心攻击任务或其他建筑胜利。
3. 每方只有开局20个单位；被击毁永久退场。能源归零、失能、无弹药、无可达路线或AI判断无法获胜均不算被击毁，不单独触发判负。
4. 全灭指该方开局全部20个单位均已被击毁，包含无人机和保障车；只剩失能或无武器单位仍不算全灭。兵营不计入存活单位数。

### 1.2 同一步裁决优先级

完成同一步双方伤害、服务、占领、据点收入与击毁分汇总后，按以下顺序只裁决一次：

1. **双方全灭：** 比较该步末总分，高者胜，同分平局。
2. **仅一方全灭：** 全灭方立即判负，另一方胜；即使全灭方同一步先达到1500分也不改变结果。
3. **双方均未全灭：** 仅一方达到1500分则该方胜；双方均达到时比较步末总分，高者胜，同分平局。
4. 均未满足以上终局条件但到达3600仿真秒：比较步末总分，高者胜，同分平局。

不按阵营遍历顺序抢先判胜，不提前截断同一步合法攻击或据点收入。终局后停止规则推进、规划和得分，仅排空已确认播放结果。技术中止不属于竞技胜负，按第14节处理。

## 2. 固定共同决策步长与实机演示

**唯一规则时间为仿真时间。** 每60仿真秒是双方共同决策的一轮，每5仿真秒是执行结算的一步；实机画面的播放进度只是已确认结果的消费位置，不是第二套战斗时钟。现实秒只用于规划预算和观看耗时。下文保留`T_authority`与`T_playback`作为计算进度／播放进度的标识，不让两者各自驱动战斗规则。

### 2.1 权威时间与指挥机会

| 项目 | 规则 |
| --- | --- |
| 权威仿真步 | 固定5仿真秒，最长720步／60仿真分钟 |
| 普通规划边界 | 0、60、120……3540仿真秒；每边界双方共同一轮，终局后不规划 |
| 规划屏障 | 双方从同一权威时刻的各自合法视图规划；等待双方完成和校验后同时采用，快者不得提前执行或额外规划 |
| 整轮预算 | 每方120现实秒，角色、工具与一次格式修复共用预算；等待另一方不产生新轮 |
| 权威推进 | 采用后按5秒步计算至下一个60秒边界或提前终局；不受画面倍速驱动 |
| 战术控制 | 双方AI全自主；人仅可赛前配置和技术管理，开局后不得人工指挥 |
| 时间冻结 | 规划等待、缓冲背压、技术暂停均不推进战斗、移动、占领、资源或冷却；它们不是额外战术机会 |

普通规划不再采用“异步返回即生效／忙则跳过”的旧机制。同步屏障消除先返回先行动及因推理快慢错过规划轮的结构性差异；同模型、预算、工具权限、隔离、故障处理仍须验收，不能据此宣布所有计算公平问题已解决。

v1.2不启用天气、随机事件、随机故障、随机命中、暴击、经验、等级、科技和装备成长。没有未定义的隐藏加成。

### 2.2 已确认结果缓冲与连续演示

1. `T_authority`为已提交权威时间，`T_playback`为画面已播放时间，缓冲`B=T_authority-T_playback`，单位均为仿真秒。必须始终`0≤T_playback≤T_authority≤3600`。
2. 普通每轮对应60仿真秒、12个已提交执行步，不是一个单位的单条命令。开播前缓存3轮，即180仿真秒。若180秒前终局，已有结果直接开播，不等待凑满。
3. 正常目标领先画面2～3轮。只在规划边界且`B≤120`时可启动下一普通轮；初始填充同样遵守此门槛，每轮最多新增60秒，因此`B≤180`。缓冲满时等待消费，不额外推理，不消耗未启动轮的120秒预算。
4. 同一时刻最多有一组双方共同规划和一段权威推进；等待缓冲不得让任一方额外检索、重规划或预知下一快照。
5. 已提交执行步可逐步进入缓冲，不能展示计划预测、未提交伤害、未结算分数或占位动画充当事实。正常目标不是硬性最小缓冲，慢推理时允许低于120秒。
6. 播放自动速度按每个5仿真秒播放步起点的剩余缓冲选择；该播放步速度固定，消费一段已提交事实后重算。画面插值只表现已确认轨迹。

| 剩余已确认画面B | 自动播放速度 |
| --- | ---: |
| B≥120仿真秒 | 2倍 |
| 60≤B＜120仿真秒 | 1倍 |
| 0＜B＜60仿真秒 | 0.5倍 |
| B=0 | 0，停在最后已确认时刻并显示计算中 |

7. 缓冲耗尽后进入补缓冲状态，即使新来5／60秒也不立即反复开停；补足120秒后恢复，已权威终局则不等门槛，播放全部剩余结果。开播和恢复门槛只限制消费，不阻止合法生产。
8. 自动降速与恢复均记录；播放速度不改变任何权威参数、AI轮次、脱战计时或现实超时。正式基线不允许主持人用手动加速绕过本表；技术停播只能停止消费，不能加给一方指挥机会。
9. 理想全程2倍播放的60分钟战斗片段约30现实分钟，但还存在预缓存、推理、降速、加载和技术暂停；不承诺总时长30分钟或任意延迟下永不停顿。每轮60仿真秒若平均推理超过30现实秒，仅靠有限缓冲不能维持全程2倍。
10. 终局是权威事件；权威停止后只排空展示缓冲，界面到对应播放时刻才宣告胜负。不在权威终局后生成战斗、规划、得分或复活。

## 3. 开局与首次AI规划

1. 双方在各自允许范围完成赛前配置，部署草稿相互保密，不可通过界面窥视敌方兵营和单位。
2. 校验编制、兵营、预部署位置、地形、静态占地和敌对地面单位非重叠、规则／地图／可见性版本，锁定配置；友军重叠不作为本版开局拒绝理由，但每辆单位仍须有合法地表、路线和静态占地；其他条件不通过则不开局。
3. 每方20个单位直接处于合法预部署位置，资源满值；**全局仅此一次配置开局部队，没有出生保护，也没有战中生成**。
4. 权威保持0秒，根据合法观察源生成双方各自初始快照。双方同时启动首次规划，每方整轮120现实秒；先完成者等待，不行动或额外规划。
5. 双方均完成校验后在同一0秒边界采用；独立任务允许按第14节部分接受，不要求每条命令均合法。
6. 计算0～60秒结果，再从60秒各自合法视图共同规划下一段；同样计算至120、180秒。按第2节控制生产与开播，不能先把三轮都用0秒旧快照推理出来。
7. 初次轮计作0秒轮，后续正常轮仅在60秒网格边界，不因现实等待增加轮数。首次失败走统一技术恢复，不让另一方先开战。

## 4. 双方固定编制与基础参数

每方 **20个开局固定单位：4侦察无人机＋12地面作战单位＋4保障车**。双方数量、类型、能力、资源上限与永久退场规则完全相同。

| 参数 | 侦察无人机 | 地面作战单位 | 保障车 |
| --- | ---: | ---: | ---: |
| 数量 | 4 | 12 | 4 |
| 耐久上限 | 40 | 100 | 80 |
| 自身能源上限 | 100 | 100 | 100 |
| 速度（米／仿真分钟） | 800 | 400 | 300 |
| 5秒最大基础移动量（米） | 200/3 | 100/3 | 25 |
| 基础移动能耗／公里 | 5 | 8 | 10 |
| 基础观察范围（米） | 1400 | 900 | 700 |
| 武器弹药上限 | 无 | 60 | 无 |
| 可攻击 | 否 | 是 | 否 |
| 可占领／争夺据点 | 否 | 是 | 是 |
| 静态／敌军阻挡默认半径（米） | 停靠时2 | 2 | 3 |

无人机在飞行状态额外消耗 **2能源／仿真分钟**，悬停同样消耗，飞行移动能耗另加；合法停靠时不扣飞行维持能源（D-02）。保障车自身能源与服务库存分离：开车不扣服务能源库存。

保障车满库存：**能源200、弹药120、维修材料100**。维修1耐久消耗1维修材料。保障车没有可射击武器，“弹药库存”不是自己的武器弹药。

整局不增加单位、不购买部队、不生产、不增援、不替补、不回收再生、不叠加升级。单位标识固定且不复用，死亡后不可恢复；兵营不能补出新单位。上述半径用于静态占地、敌对地面实体阻挡和合法停靠面检查，不再用于拒绝友军停车重叠。

## 5. 部署区域与兵营

### 5.1 部署区域保持现状

地图使用米制 `x,z`，高程为 `y`，范围12000×12000米。

| 阵营 | x范围 | z范围 | 矩形面积 |
| --- | --- | --- | ---: |
| 红方 | 1000～1900 | 3200～10400 | 6,480,000平方米 |
| 蓝方 | 10000～11200 | 1600～8800 | 8,640,000平方米 |

完整单位／兵营静态占地必须合法，不能只检查中心；友军单位之间的重叠暂不处理。双方可以在各自部署区内合法自由预部署，不得进入据点有效区域。**不缩小蓝方可用区域来暗中制造对称。** 区域面积不同是已知公平性风险，不据此直接断言一方胜率。

### 5.2 兵营

- 每方保留三类兵营，各类一座；赛前可在本方部署区合法选址，开局后固定，不能增建、迁移或占领敌营。
- 可建在合法非道路地面，不要求贴近道路；旧“距道路节点不能超过某数值”的测试限制不继承。
- 完整占地不能碰水、实体建筑、其他兵营或非法坡面；不能堵住道路、桥头与必要通路。
- 默认兵营占地60×60米，边界、出口及服务锚点随地图包冻结（D-03），不是将当前显示模型大小直接当规则占地。
- **兵营不可被攻击、摧毁或功能性压制。** 敌军可占住合法出口空间或道路，造成初始出营、返营或补给通行受阻，但不改变兵营功能状态。
- **兵营实体占地阻挡移动与停车，但不阻挡观察和射击，不提供掩体。** 普通地图建筑仍正常遮挡。
- 没有仓库、机场或装饰性设施的免费补给；只有明确列入本稿的兵营与保障服务有效。

兵营只承担赛前编制部署、初始出营和存活单位补给，开局后不会生成任何单位。地图旧营地、旧任务设施或装饰性建筑不能自动成为新胜利目标、观察源或攻击源。

## 6. 移动、道路与集群排列

### 6.1 通行范围

1. 本方部署区内，本方地面单位可在合法地面自由移动，包括预部署、初始出营、返回和重新定位；道路与合法空地使用相同基础速度和每公里能耗。
2. 按完整合法路线的最短旅行时间寻路，时间相同时优先道路，不强制先绕去找路。
3. 离开本方部署区后，地面单位只能走合法道路、桥梁及经核验的初始出营／任务／服务接入段；不自动生成越野捷径。道路不按阵营专有，默认双方均可双向使用。
4. 敌方部署区不是本方自由越野区；不能穿过水域、墙、不可通行坡面或道路外树林。树林内的合法道路可以通过，但不赋予任意林间越野权限。
5. 桥面与桥下分层，二维交叉不等于路口，跨层必须有明确合法连接。
6. 无人机使用合法二维航线，不受地面道路约束；地面建筑不自动禁飞。正式地图须提供空域政策，不能穿越未定义禁区。
7. 不继承旧快速／倒车倍率或坡度减速表；本版仅采用第4节基础速度，不可通行坡面由地图核验。

### 6.2 友军集群与逐单位判定

- **友军移动和停车均互不阻挡，不限数量、类型和方向；出现友军穿模暂不处理。** 不再分配竞争性停车名额，不因友军重叠而排队、退让或拒绝路线。
- 集群参考现有纵队跟随表现，仅是移动和停靠排列，不是合并成一个规则单位。现有部署试走的专用速度、测试能源、同营同型筛选和近距离拒绝条件不自动成为战中规则。
- 每辆单位保留独立标识、真实规则位置、合法路线、速度、能源、耐久、弹药、任务、观察、射击和服务状态。领车到达不代表其他成员到达；阵型图标和渲染偏移不算规则位移。
- 集群成员受阻或失能时按自己的规则停止，不因单个成员停止就强制整队停止。其他成员只有在自身路线合法且不穿越敌军时才能继续；友军无阻挡不等于能越过敌军封锁。
- 排列、调整间距和停车如改变真实位置，必须经过真实路线、时间和能源结算；不得瞬移到目的地附近。没有友军最小间距的竞技硬门槛，不借队形为位于范围外的成员补算占点、射程或100米服务资格。
- 无人机空中不做单位间碰撞；合法停靠仍检查静态地表与服务条件。友军停靠重叠不再启用旧停车位竞争，但不得穿入建筑、跨层或隔水接受服务。

### 6.3 敌对地面单位阻挡与合法停止

1. **敌对地面单位相遇会相互阻挡，移动或停车均不能相穿、推挤、无空间交换位置。** 以第4节各自占地半径和1米安全余量检查；这是敌军实体边界，不是射程或服务范围外扩。
2. 使用同一步双方完整运动轨迹统一检查接触，在接触前停止；不能只检查终点，不能因高速交叉或内部处理顺序穿过敌军。既有合法占用不因轮换被驱逐，普通迎面冲突不靠阵营优先权放行。
3. 静态地形、敌军实体及能源预算仍须合法。前方无路时报告受阻并停止；有合法绕行路线且处于已有任务授权范围时才可绕行，不自动创造新战略目标。
4. 每辆单位提前验证本步能源和合法停止位置，非零但不足下一安全行驶段时提前停止，只扣实际行驶消耗。这里的“合法”不要求与友军分离，但仍不能停在敌军实体或非法静态地形内。
5. 本步移动时仍存活、随后伤害阶段被击毁的敌军，不追溯撤销已经形成的阻挡；下一步其残骸不再阻挡。残骸仅视觉表现，不遮挡、不减伤。
6. 不能因集群队形、等待时长或碰撞回执获得免费位移、下一步额外速度或隐藏敌军精确情报。复杂友军停车分配与联合非重叠求解仅作为后续建议，不是本版要求。

## 7. 观察、树林与信息边界

### 7.1 观察与射击分开

所有有效观察源每5秒更新，本方即时共享；射手仍独立检查自己的射程和射击线路。初始0秒也计算合法观察。失视后保留最后发现记录和时间戳，不实时更新隐藏位置、耐久、弹药或行动。

规则采用简化高度判定：固定建筑阻挡体、地形三角面、桥面分层，不直接取渲染模型／帧率／摄像机。观察和直射引用同一实体遮挡目录，分别从各自起点检查。v1.2 不启用弹道抛射、透射、楼层驻扎和高地射程加成。

技术默认：范围用水平中心距；规则观察、射击与目标判定点均为所属支撑表面上方2米，无人机也不使用画面48米高度。建筑使用版本化有向占地和高度，地形按已存在的三角插值规则，射线对规则三角面／阻挡体作完整相交检查，不以稀疏采样漏过山脊；非目标实体相切按遮挡处理。源和目标自身实体不自挡，其他普通建筑正常挡；几何容差0.01米仅消除数值误差，不放大射程或占点圈（D-05）。桥面遮挡厚度等必要几何缺失必须阻止该场景发布，不能按无厚度穿射。

### 7.2 无人机树林规则

| 情况 | 距离条件 |
| --- | --- |
| 无人机在林外，目标在林外 | 基础1400米，另检查实体遮挡 |
| 无人机在林外，目标在林内 | 总距不超过1400米，且从射线进入目标所属林区的位置到目标不超过600米 |
| 无人机在树林内 | 观察范围1000米，不反复叠减400米 |
| 无人机在林内观察同林目标 | 使用1000米，不额外压成600米 |
| 无人机在林内观察林外目标 | 使用1000米 |
| 离开树林 | 恢复1400米 |

树林不阻挡子弹、不提供减伤；地面单位与保障车不因树林额外缩减900／700米视野，仍检查建筑和地形遮挡。

森林边界与多个林区的编纂默认见 D-06。没有森林几何不能把树木材质颜色当精确规则范围。

### 7.3 公开与隐藏

公开：地图规则地形、道路、5个据点位置及归属／争夺状态、双方部署区、总分、比赛时钟与终局结果。

仅本方完整可见：本方单位／兵营、资源、任务、等待状态、AI运行情况。

敌方兵营位置、初始和实时部队、耐久及资源须依赖合法观察；失视后只保留最后合法记录及时间戳。发现兵营不等于发现旁边部队或内部初始驻留单位。公众据点状态不得泄露敌方身份、数量、精确坐标。隐藏阻挡只回报“前方受阻／条件待核验”，不能凭碰撞回执透视。

展示时间边界：上述公开／私有划分适用于同一个逻辑时刻。AI只取权威时刻各自合法视图；比赛画面、HUD、单位详情、战报、得分曲线和终局通知只取播放时刻，不能混读领先2～3轮的权威状态。管理员技术通道单独鉴权；全局调试数据不得转入AI输入。播放不回写权威世界，回放不重新触发伤害、服务或计分。

## 8. 据点、占领与积分

### 8.1 布局

共5个等值、初始中立的据点：双方各2个上下分散的本岸近点＋1个中央桥头陆地点。中央只允许指定陆地表面参与占领，不允许桥面、河床、对岸重叠层凭平面距离占领。

半径 **250米** 为首测值，有效区域为圆盘与批准地表掩码的交集；空中单位不能占点。具体坐标尚未通过地图发布验收，见第17节。

### 8.2 资格、争夺与进度

1. 地面作战单位、保障车可占领与压制；无人机、能源0、耐久0不合格。步初能源0者即使当步补能也不追补资格。
2. 中立点占领30秒；敌方点先中立化30秒，再占领30秒。人数不加速。
3. 移动后、伤害前，对每个点冻结合格双方在场集合`S_point`。收入压制和争夺清零共用该快照，不能一个查整步轨迹、另一个查终点。
4. 进度每步5秒。同一步至少一名本方合格单位**完整停止在有效区域且伤害后仍存活**才可增加；当步进入不能补算驻留，路过不贡献进度。持续合法停驻时可射击、服务或接受服务。
5. `S_point`双方都有合格单位，或当前占领阶段的对方在快照中有合格单位：该步争夺，保留原归属，当前未完成阶段清零。已完成中立化不回滚。对方在快照后同一步被击毁也不追溯取消争夺。
6. 若没有第5项争夺，但本阶段无完整停驻的合格存活单位，未完成进度清零；若中立点只有另一方的合格完整驻留者，可开始其新阶段。阶段方转换不继承敌方未完成进度。
7. 唯一占领者最后伤害结算死亡，不获本步进度，未完成阶段清零。单纯途中经过且不在`S_point`的敌军，不压制也不额外触发争夺清零。
8. 取得归属后离开仍保留，不要求驻军；当步结束取得的归属，下一步才可供收入使用。

### 8.3 收入与统一压制

每个己方据点每完整5秒 **1分**。该步归属必须稳定，且`S_point`无合格敌军。新占领在步末完成，下一完整步首次收入；如30秒完成、35秒首次得分。

敌军单独在原主无人点内，也会压制收入；不要求双方驻军同时在场。移动中但快照时在点内的合格敌军可以压制，不等于能获得占领进度。

仅途中经过、快照时已离开，不压制；快照内的敌军随后同一步被击毁仍压制该步，下一步重查。能源0不压制，失能也不自动取消旧归属。D-07冻结本版压制与争夺的统一口径。

### 8.4 击毁分

| 被击毁对象 | 得分 |
| --- | ---: |
| 敌方侦察无人机 | 5 |
| 敌方地面作战单位 | 10 |
| 敌方保障车 | 8 |

击毁分归本阵营，不按参战人数分发或重复累加。一次死亡事件仅计一次，超量伤害、多个射手、重放和重复提交不能重复加分。没有首次击毁奖金；不复活、不产生可再次计分的新生命，同一个敌方单位整局最多贡献一次分值。

能源归零不是击毁，不给分。伤害只来自敌方合法攻击；兵营不提供攻击或防御伤害。击毁一方全部开局编制的分值合计172，但全灭另按第1节直接裁决，不能把172理解为击毁流达到1500分的必经要求。

## 9. 攻击、弹药与目标选择

### 9.1 地面武器

| 项目 | 参数 |
| --- | ---: |
| 攻击间隔 | 10仿真秒 |
| 每次攻击消耗 | 1武器弹药 |
| 对地面／空中单位伤害 | 16 |
| 对地面单位射程 | 600米 |
| 对空中单位射程 | 800米 |
| 移动射击伤害倍率 | 0.6，即对单位9.6 |
| 移动射击当步移动能耗倍率 | 1.25 |

无友军伤害、溅射、穿透、掩体减伤和随机命中。单位不阻挡子弹；兵营不挡视线／射线。合法确定性攻击只伤害所选目标，超量伤害不转移到下一目标。

每次射击须满足：已获任务授权、当前可见、距离、射击线路、存活、有正能源、弹药、冷却及目标可受攻击。取消的不合法攻击不消耗弹药或刷新冷却。首次冷却就绪，可在第一步合法攻击时开火；此后按实际开火边界加10秒（D-08）。

实际位移大于0才使用移动伤害倍率；单纯持有移动任务但本步完全等待，不自动减伤。移动射击能源先按可能开火预留1.25倍预算；最终没有开火则只结算基础移动能耗，不追加移动距离；不能先花光能源再追补开火成本（D-08）。

双方攻击意图在伤害提交前统一冻结，同步结算，允许互相击毁。受到非致命伤害本身不取消已合法的攻击；接受服务的单位本步不能攻击。

### 9.2 授权范围与默认选敌

- 普通已授权交战范围内，可按“最近合法当前可见目标，等距优先剩余耐久低者”执行，也可使用AI明确的集火／分火策略。
- 彻底同距同耐久以规则包冻结的轮换次序处理，不按红蓝循环顺序（D-04）。
- 失视立即停止针对该目标的精确射击；不得向历史坐标继续精确命中。
- 只可在AI授权范围内改选当前可见合法目标；不能因新观察擅自追击或创造新战略任务。
- 失视不创造新的追击路线；原有合法路线是否继续取决于已授权任务。缺弹暂停按第10节处理。

## 10. 缺弹与攻击受阻的默认行为

1. 弹药耗尽时停止射击，并暂停该攻击任务的接近移动；在符合第6节地形、敌军阻挡与能源条件的位置等待，保留任务并报告。
2. 不因缺弹自动返营或自行寻找保障车；有AI明确的补给、撤退或其他条件分支时，执行该合法预案。能源触线另遵守第11.0节，不增加AI机会。
3. 失视、超射程或线路受阻时不得继续精确命中；是否沿原路线移动取决于已有任务授权，不额外创造追击目标。
4. 受阻等待不是无敌状态，仍可能被敌军攻击。友军停车重叠不阻止停止；敌军及静态地形的非法重叠不能用瞬移、推挤或强行冻结解决。

## 11. 能源、失能与补给

### 11.0 能源补给底线与路程预留（已确认补充）

**无人机、地面作战单位（步战车）和保障车的自身能源补给底线统一为30点，即100点上限的30%；双方同等适用。** 保障车自身能源与用于服务他人的能源库存分开计算，不能把库存当作自身续航。

补给触发线为：

> `E_trigger = max(30, C_service + 10)`；自身能源 `E ≤ E_trigger` 时触发补给安排。

`C_service`是从当前位置抵达合法补给位置、直到满足服务条件前的预计自身能源消耗，按合法路线、移动方式和预计等待计算；无人机另计飞行移动、飞行维持及空中等待消耗。10点是决策安全余量，不是免费能源、不可消耗能源或续航保证。例：预计消耗28点，则38点及以下就应安排补给，不等到30点。若预计消耗加余量超过100点，不把触发线截为100；应重新安排补给位置或任务，不能因满能源就认定路线安全。

1. **触发后的任务方向：** 停止继续深入、追击等增加能源风险的耗能任务，转入合法补给安排；不把30点当成失能线，不自动取消正能源单位的观察、受击或其他原有资格。能源0仍按第11.1节处理。
2. **先确认服务可行性：** 选择兵营或保障车前，确认合法接近路线、同一服务地表、100米服务距离、可用停车／停靠位置，以及服务方的库存或服务资格。不能只按直线最近选目标；没有可确认的路线或服务条件时，标记补给不可确认／受阻，不把未知消耗当作0，也不虚构可用补给点。估算仅使用本方合法信息，不泄露隐藏敌军或保证未来路线不会受阻。
3. **各兵种安排：** 无人机须前往保障车或兵营能够合法服务的停靠点，不能仅飞到保障车上方悬停加油；地面作战单位沿合法道路／接入段接近服务方，或在合法停车点等待保障车；保障车可请求其他保障车补自身能源或返回兵营，但不能用自己的库存给自己加油。仍沿用第11.2、11.3节的停止、来源、吞吐和脱战限制，不扩大服务范围或地面通行权限。
4. **不增加AI机会或自动战略任务：** AI在每次合法规划中必须检查补给触发条件，安排原任务时预留至下一规划边界前的消耗；预计途中触发时，应预先授权低能源转向、路线和补给安排。执行器每5秒仅按已有合法任务／预案检查执行，或等待下一次合法AI指令；不得因触线额外调用模型、自动创造撤退目标或恢复死亡单位任务。对已知将触线的持续深入任务应调整，不能明知风险仍等下一轮才处理。
5. **记录与失败边界：** 记录自身能源、预计消耗、触发线、估算所用权威时刻、目标服务位置、授权来源和受阻原因；显示仍按播放时刻投影。没有可行补给安排并不产生瞬移、越野救援、免费能源、自动回收或再生。阈值只预防搁浅，不保证任何位置均可救援；不新增补满后出发阈值。
6. **无人机空中断电仍待明确：** 本条不新增自动降落、坠毁、降落能源消耗或应急停靠流程。空中能源归零的状态转换及合法降落流程仍须另行确认、实现并验收，不能将30点底线写成已经解决该缺口；相关流程未明确前不能通过对应运行发布验收。

### 11.1 能源归零

能源0是失能，不是被摧毁。不得移动、攻击、产生新观察、提供服务、占领或争夺；保留地面实体占地，可被攻击、可接受合法服务。

不自动死亡、回收、返营或恢复。已取得据点归属不自动取消。区外搁浅依赖现场救援；若本来就在合法兵营服务位置，也可接受兵营服务。

本步补能到正数，最早下一步恢复行动、观察和占领资格；不能同一步先加油再移动／攻击。非零能源但不足下一安全行驶段时提前停车，不强制扣成0或把失能和低能量混为一谈。

### 11.2 野外保障车

- 供需双方本步完整停止、处于合法可达的同一服务地表，距离不超过100米；无人机须在合法停靠点，不允许隔空给飞行中的无人机补给。
- 每车每5秒服务 **1目标、1资源**：补2自身能源，或2武器弹药，或2耐久。
- 扣同量对应库存；维修材料按1:1。不能超出接收方上限，也不能库存负数。
- 同一接收方每步仅一个服务来源、一次服务，不叠加多车或兵营。
- 可给其他保障车补自身能源／耐久，不能野外自我服务；不能野外凭空恢复保障库存。
- 接受服务者本步不能移动或开火；保障提供者不能同时移动。合法完整驻留时仍可占点。
- 伤害先于服务。非致命命中不自动中断服务，致命伤害后不能被同一步维修救回；死者不能提供或接受服务。

### 11.3 兵营补充

本方三座兵营均可服务所有本方单位类型。距离服务锚点不超过100米，必须有合法到达和接触条件；隔墙、隔水、跨桥层不算可服务。兵营自身不挡射线不等于允许穿越其实体进行服务。

**兵营脱战门槛：** 在本步服务结算边界`u=t+5`，单位连续15仿真秒未开火且未受到实际正伤害，才能接受兵营任何补充。记录本单位本局`last_fired_at`与`last_damaged_at`，均按实际事件提交边界计；从未发生对应事件记为空，不虚构新生受伤。条件为每个非空时间戳均满足`u-last_event_at≥15`。

- 本步先伤害、后服务；本步实际受伤将时间戳更新为`u`，立即失去兵营服务资格，即使伤害非致命。不合法而拒绝的攻击、0实际伤害不刷新受伤时间。
- 5秒开火且此后未受伤，最早可在20秒结算接受服务，前提是15～20秒完整停止、预先申请且不射击。10秒的冷却空档不能补给。
- 本单位本局开火／受伤时间不因现实推理、停播、任务刷新或排队而清空；整局没有新生命实例，也没有通过再生重置历史的机会。仅在脱战不足时，不占实际服务名额，不凭排队绕过门槛。
- 对所有兵营补充项目和所有单位类型一致适用；不要求脱战后再驻留15秒。野外保障仍允许非致命受击后服务，不增加该门槛。

每座兵营每5秒最多服务 **4个单位**，同一单位不能占多座兵营名额；一个单位占一个名额，可同时补齐以下各项，但不超过容量：

| 每5秒补充项目 | 补充上限 |
| --- | ---: |
| 单位自身能源 | 50 |
| 单位武器弹药（如有） | 50 |
| 单位耐久 | 50 |
| 保障车能源库存 | **50** |
| 保障车弹药库存 | 60 |
| 保障车维修材料库存 | 50 |

保障车能源库存补充量采用最后修改的 **50，不是100**。兵营库存无限，但吞吐有限。保障车接受兵营服务时可同时恢复自身与库存，仅占1名额，不能同一步提供野外服务。

排队优先级由AI指定；同优先级按连续等待更久者先；仍同序按阵营内轮换。未指定视为相同默认优先级。全满、死亡、离开范围者退出；离开后重新进入不保留连续等待时长。队列不自动提升策略优先级，可能被高优先级任务长期压后，须记录（D-10）。

服务意图在伤害前锁定：本步计划接受服务者不同时开火，即使随后因受伤而失去兵营资格，或野外服务源被击毁，也不追溯补发攻击。伤害后按脱战与其他资格过滤，再分配名额；可递补预先申请且完整停止的候选，不能事后把已开火者改成接收者（D-10）。

## 12. 死亡与固定编制永久退场

1. 耐久降到0即被击毁；记录唯一死亡事件，撤销该单位活动任务、待执行队列和未完成服务。一次死亡只记一次击毁分，不因多个射手、补交日志或回放重复处理。
2. 被击毁单位永久退场，不能移动、观察、攻击、服务、占领或争夺；不能被同一步或后续维修救回。残骸只作视觉表现，不阻挡或遮挡。
3. **没有复活、再生、替补、生产、增援、回收重建或离图等待生成。** 单位标识不复用，死亡槽位不再填充；兵营不能恢复兵力。
4. **没有出生保护或死亡后保护。** 开局单位直接按普通规则参与；本版也不存在借保护穿行、保护期结束或保护区域获得的特殊资格。
5. 每步以开局固定名册统计存活数：未被击毁者都计存活，包括能源0、无弹药、合法停靠或暂时无任务者。兵营不计入存活数；不能把失联／不可见当作死亡。
6. 同步提交双方伤害、死亡和击毁分，再在完整步末按第1节判定全灭及其他胜负。全灭发生的本步仍完整结算合法据点收入，不预先抹除归属；终局后不再继续收入。
7. 死亡单位的迟到命令、重复伤害、旧分支回执不能更改当前状态；存活单位不因队友死亡自动继承其战略任务。

## 14. AI任务、共同采用与技术暂停

### 14.1 权限与任务

每方总指挥、侦察、陆兵、保障角色只读本方权威时刻允许信息，输出结构化任务。执行器处理合法动作，不创造战略目标、分数或能力。

AI可预设撤退条件、路线、补给安排、交战范围和依赖；执行器每5秒检查。能源补给须同时遵守第11.0节的30点底线和路程预留，但不新增规划机会或无授权战略任务。没有有效任务则待命，不以固定脚本伪装规划成功。本版没有死亡单位自动再生或任务继承。

### 14.2 同步规划与部分接受

1. 0、60……3540秒边界且未终局时，按第2节背压启动双方同轮规划；相同权威时刻不代表双方拿到相同敌情，必须各自裁剪视图。
2. 输入绑定分支、规则／地图／可见性版本、权威快照、轮次与固定单位标识。规划期间权威状态冻结；播放可继续消费旧结果，但不反向改变输入。
3. 双方均返回并校验完才共同采用；先返回者不能执行、重新看播放结果或增加推理。到下一60秒边界前不启动另一普通轮。
4. 独立合法任务采用，非法及其依赖拒绝；未修改单位保留仍合法旧任务，否则待命。共同采用不等于因一条错令清空全队。
5. 回执不能泄漏隐藏敌情；猜测不构成可执行情报。待采用结果不得被模型、对方或比赛画面预览。

### 14.3 整轮超时与修复

**每方120现实秒是整轮从启动到完整方案返回的总预算**，包含指挥／兵种角色、工具和格式修复，不按角色、重试或请求重置，不受播放速度影响。完整合法可解析结果恰在120秒返回可接受，超过则超时；后续确定性校验不得被当作延长模型推理的通道。

格式无法解析只允许1次修复，用原冻结输入且包含在剩余预算。格式正确但有非法任务走部分接受，不无限重试。任一方超时或修复后不可用，废弃该未采用的双方轮次，进入全局技术暂停；不得先执行成功一方。

### 14.4 故障恢复与播放

1. 保持最后已提交权威状态，不回滚移动、伤害或分数。双方在途／未采用方案失效，迟到结果仅日志。
2. 管理员仅技术排障，不给战术命令、不单边更换模型／提示词／预算。显式启动双方恢复轮，各自从暂停时刻合法视图规划，新的120现实秒。
3. 双方完成后同边界共同采用。每次故障最多2轮恢复；仍失败保持暂停，放弃记技术中止、不计竞技胜负。
4. 恢复轮覆盖当前边界待采用的轮次，不在同一边界再启动普通轮；若暂停位于非60秒边界，可恢复后执行至下个正常网格，不能追补历史轮。
5. 人为技术暂停同样废弃双方未采用结果并共同恢复，不能改名重置故障次数。单纯缓冲背压／开播等待不属于故障，不触发额外恢复轮。
6. 已确认播放结果可继续消费至权威暂停处，再显示等待；管理员故障通知可立即显示但不得包含未播放战斗情报。技术中止则停止竞技结果输出并保留已有轨迹，不把暂时领先宣布为胜者。
7. 保存／恢复按提交号幂等；旧分支／死亡单位／轮次不能写当前对局，不因离线现实时间补算仿真。播放进度独立保存，不反推权威状态。

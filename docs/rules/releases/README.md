## 解压与运行

ZIP保留`docs/rules/`仓库相对结构，可解压到独立目录阅读，也可在确认不会覆盖其他工作的前提下解压到仓库根目录。压缩包不包含地图JSON或整个代码仓库；地图说明中的地图源链接、旧几何诊断脚本所需的地图文件，需在完整仓库中使用。仅阅读规则和运行v1.1参考自测不依赖Unity或服务。

```sh
shasum -a 256 -c docs/rules/releases/qinglan-rules-v1.1.zip.sha256
python3 docs/rules/tools/check_qinglan_v11.py --self-test
python3 docs/rules/tools/check_qinglan_v01.py --self-test
```

校验命令在仓库根目录运行；ZIP校验文件使用相同仓库相对路径。包内清单只覆盖包内载荷，不声称覆盖整个仓库或压缩包自身。

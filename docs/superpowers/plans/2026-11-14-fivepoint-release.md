# 青岚五点规则落地执行清单

> 执行方式：在当前会话逐项实施并验证；用户已要求继续落地，不重复询问已确定的规则和地图范围。

**目标：** 将当前总册的五点规则推进到可运行、可审阅的交付状态，地图外观和布局保持不变。

**规格：** `docs/rules/青岚_游戏规则总册_分类目录完整版_v1.1.md`。

**架构：** 沿用Python规则核心、PostgreSQL事务和Unity完整帧播放。规则地图只能从当前发布几何提取，禁止使用移动测试网格冒充正式规则地图。缺失或矛盾的数据须输出具体位置和原因。

**技术栈：** 现有Python标准库、项目已有FastAPI／psycopg／Pydantic、Unity 6000.6.7f1；不新增依赖。

## 全局约束

- 仅处理本次五点规则及直接相关发布链路，保留既有未提交修改。
- 不重新生成地图、不移动桥梁、点位或建筑。用户后续明确允许仅修三桥六处接坡；相应路面高程、地图共同身份和场景身份可同步，其他地图内容保留。
- 不篡改已登记迁移摘要；先确认历史文件来源，再进行兼容升级。
- 模型密钥只核对是否就绪，不输出内容；真实调用失败不自动重试。
- 测试替身、真实HTTP、原生构建、界面验收和正式整局分别记录。

## 接口

### `SurfaceCatalog`

```python
from backend.battle_map_surfaces import (
    SurfaceCatalog, build_catalog, seal_catalog,
)

payload = build_catalog(assets)
catalog = SurfaceCatalog(assets, payload)
catalog.layer(surface_id)
catalog.triangles(surface_id)
catalog.height(surface_id, point_xz)
catalog.footprint(surface_id, polygon, *, side, purpose,
                  kind='ground', direction=None)
catalog.center_surface(surface_id, point_xz)
```

`build_catalog` 将地图定义、网格摘要、基础标注、部件和原始三角索引绑定到同一目录。`face_id(geometry_sha256, part_id, triangle_index)` 是稳定的原始面身份。`seal_catalog` 只提供摘要封存工具，不等同于语义批准。

catalog layer 必须同时具有 explicit support/overlays/solids/access resolution、真实 `support_faces` 原三角索引、连续高度、显式 access permission 和合法用途；缺任一项即拒绝。客户端提供的 surface id、路线或合成测试语义不授予权限。

导出 JSON 保留来源事实、网格部件和待实现技术项，但不把所有事项标为“待用户审批”：已有来源事实和技术映射工作，与需要用户/场景验收的战斗语义是三类不同问题。

### `MapMotion`

```python
motion = MapMotion(catalog,
                   surface_transition_persistence=False).plan(
    unit,
    [{'surface_id': '...', 'end_m': [x, z]}, ...],
    seconds=5,
    moving_attack=False,
    extra_solids=(),
)
all_motion = MapMotion(catalog).motions(
    state,
    route_resolver=trusted_server_route,
    start_positive=set(), service_locked=set(), transitions=set(),
)
```

路线必须由服务端 resolver 产生；客户端路线不授予道路/桥梁/森林权限。地面单位使用规则半径加 1m 的外接正方形做完整 swept footprint 证明，因此是安全保守的：会拒绝某些真实圆形可通过的紧弯通道，不会缩小单位半径。扫掠为精确凸包，不使用固定采样；检查真实三角、薄墙/孔洞、静态据点、坡度、停车、时间/能源及同步敌对碰撞。友军在后续运动中不作为阻挡物。

当前明确限制：空中运动由工作台2提供；这里只拒绝未接入的 flying recon，不把飞行伪装为静止。跨层只允许独立接受的显式 portal，并要求两层完整 footprint 支撑和相同真实高度；不实现一般相邻层 straddle，也不能用跨层连接修复台阶。尚未提供冻结导航搜索或时间/能量最优路线搜索。

`arc_length` 对平方根可精确表示的有理长度直接保留精确有理数；不可精确根目前使用内部微米向上界并用 exact arithmetic 校验。这是保守几何算法，不是总册规定精度。原总册21.2与地形5.2仍规定0.001米位置和累计路径精度；用户随后仅回撤未落盘的1米调整，未授权修改总册。本文件不再将内部微米界或碰撞二进制定时当作规则。内部更高精度只用于预算/连续扫掠证据，不扩大合法支撑或交互范围。

本次1米调整没有落盘，已按用户要求仅取消该调整；总册21.2、地形5.2仍是 **0.001米**，未修改总册。资源、耐久、得分精确累计，60秒每轮/最多60轮不变。

`Motion` 由工作台2追加以下字段，均放在末尾以兼容原位置参数：

| 字段 | 类型/默认值 | 含义 |
|---|---|---|
| `surface_id` | `str | None = None` | 实际毫米停止点所在层，不因清余数丢失 |
| `interrupted` | `bool = False` | 受阻/能源耗尽/敌对碰撞/停止，不同于正常5秒结束的unfinished |
| `budget_segments` | `tuple | None = None` | 本步连续预算证据；不先按内部三角或地形段取整 |
| `segments` | `tuple`（既有） | 累计记录路径的实际收费增量；合计为整毫米，跨地表分摊可为有理数 |

- `finished=True` 仅表示路线到达。`interrupted=True` 表示受阻、能源耗尽或敌对碰撞；没有移动路线、服务锁定/过渡导致的静止也清除cursor。正常5秒用尽而路线未完且未耗尽能源时两者均False，保留同路线余数。
- `position_mm` 与 `surface_id` 是权威位置/支撑层。观察、攻击、服务、占点和当前支撑使用权威毫米位置，不能读隐藏亚毫米cursor扩大合法范围。
- `progress.exact_position_m` 是同一未中断路线连续预算末点，不再要求其直接round等于规则点；新增 `progress.rule_position_mm` 必须完整等于 `Motion.trace[-1]`。
- `progress.path_pending_segments` 为不足1毫米的FIFO尾部，保留原地表/坡度和几何起终点。`progress.recorded_distance_mm` 是同一路线已经记录的非负整数毫米累计值。`schema_version/catalog_sha256/route_sha256/leg_index/leg_start_m/leg_length_m/distance_m` 绑定路线与资产，恢复须重验目录、层、权威点及真实路线。
- `record_path_segments(segments, progress=None, *, interrupted=False)` 返回 `(billed_segments: tuple, pending_segments: list, recorded_total_mm: int)`。先拼旧pending和新continuous段，FIFO消费累计已完成的整毫米，保留不足毫米尾部；只对总长度处理精度，不对每段分别取整。arrival调用时与interruption一样丢弃尾部。
- `pending_path_energy(kind, progress)` 使用 `kernel.movement_cost` 精确计算尾部预留；下一步连续预算先保留该成本及移动射击的5/4系数，不能把未记录成本当免费能源。
- 例：道路地面三步连续预算各100000/3毫米，收费记录依次33333、33333、33334毫米，总计100000毫米，累计费用4/5。第三步账单不能再拿5秒预算重截，否则会错误拒绝补齐的1毫米；Executor验证 `budget_segments` 的时间/能源证明，用 `movement_cost(segments)` 消费实际累计记录费用，并重算FIFO证明。
- 完成/受阻/耗尽/停止/取消/新移动命令（包括相同目标重发）时，Executor先保存 `surface_id`，然后调用 `Geometry.clear_movement` 清除 `movement_progress` 和旧 `geometry_position`。新路线只从 `position_mm/1000` 开始，不能继承已清余数；旧跨路线geometry_position严格拒绝，不自动迁移。
- ground毫编码落点重新计算真高度、全占地支撑、权限、静态实体；同步碰撞同时验证continuous预算轨迹和实际毫米轨迹。安全证明不通过即拒绝，不能因量化放宽边界。微米弧长上界和二进制碰撞时间只属内部保守算法。
- 服务端端点可为 `Fraction` 或有限数值，严格 `a/b` 字符串在 `MapMotion.details` 入口统一解码后再计算摘要和几何；JSON高精度仅同路线游标证据，不是独立跨终止权威位置。

工作台2负责Executor、air、interaction契约落地。ground组件和共享helper已经稳定，可交工作台3独立检验；独立PG/完整场景验收结果由工作台3报告，不由本组件测试代替。

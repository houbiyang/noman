## 坡度实现

`backend/battle_terrain.py`直接从真实三角面计算平面梯度，按行驶方向分别取得纵坡与横坡，取两者较大值。采用有理数平方比较，避免开平方舍入将20.01%误判为20%。上坡下坡对称，不把等高线行驶认作平地。

- 精确支持10%、20%、35%包含等号的边界；禁行不是速度为零。
- 支持真实面高度查询和路线投影精确裁剪，不靠间隔采样忽略窄面。
- 桥面的计算输入必须是桥面真实三角形，而非河床高度、`surfaceHeight`常量或默认零坡度。
- `battle_kernel.segment_budget`已支持内部`grade_squared`证据并使用总册坡度档位；保留原合成几何的`grade`格式，二者须且只能提供一个。HTTP草稿不接受这些几何证据。
- 开阔地倍率仍来自总册：坦克0.65、保障车0.45，再乘坡度系数；未增加一套独立显示常量。
- 单个面的最陡坡度可供后续完整占地汇总，但**尚未完成全地图完整扫掠、服务面、层连接及路线批准**。本次不能声称地面服务或停靠已全部合法。

## 风险、失败处理与回退

| 风险 | 处理/验收 |
| --- | --- |
| 将底层open误当成覆盖层或走廊批准 | 标注明确overlays_resolved=false、grants_route_permission=false；禁止注册为生产Geometry |
| 换图后继续使用旧标注 | 绑定两份原始资产SHA256，摘要不符拒绝；不偷偷再生成或迁移对局 |
| 浮点误差改变坡度边界 | 有理数平方分档，覆盖10/20/35及刚超过上限测试 |
| 桥头或支撑层断开 | 后续真实几何核对，不能瞬移、默认补坡或将桥坡清零 |
| 既有对局被覆盖 | 不连接用户库、不修改旧网格/场景、不自动启用执行器 |

生产执行器保持未注入，独立新局入口及浏览器三席位完整演示仍待验收。失败时保留门禁，不向旧裁决回退。代码回退只移除本次新增地形基础文件与`segment_budget`的本次坡度证据补丁；不得reset整个工作区。无数据库表/迁移/配置变更，无需数据库回滚；既有局数据与旧移动文件保持原样。不要在已有对局使用新规则参数覆盖旧冻结版本。

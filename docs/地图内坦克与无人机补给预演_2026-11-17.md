# 地图内坦克互射与无人机补给预演

## 入口与边界

- 原项目页面：`http://127.0.0.1:18766/`。
- 右上角「坦克与补给预演」，或设置 → 演示结果 →「在本页地图预演：坦克互射与无人机补给」。
- 使用原 Unity 地图、原模型、原逐轮回放渲染器，在当前页面内打开大界面；不是独立 HTML/Three.js 页面。
- 地图和单位克隆至隔离显示层，关闭恢复实时地图相机；不覆盖当前对局投影。
- 只读预演不提交战斗命令、不推进轮次、不改数据库、不写入正式历史、不产生正式胜负/评分。
- 支撑面、视线及合法性使用明确的测试适配器；**不是实图通行/射线/部署合法性的验收结果**。界面始终标注该限制。
- 为便于观察，仅预演模型显示放大，事件坐标、单位位置、服务距离与资源数值不变；正式历史回放模型不受影响。

## 一轮事件与计算

预演时长60秒，12个5秒步长。双方坦克距离150米；蓝方保障车与悬停无人机水平距离50米，无人机离地30米。

| 时间 | 事件 |
| --- | --- |
| 0秒 | 坦克耐久100、弹药60；无人机能源60；保障车能源库存200 |
| 5、15、25、35、45、55秒 | 双方各射一发，每发伤害16，显示后坐、炮弹与命中效果 |
| 5、10、15…60秒 | 保障车向无人机交付2能源，显示连接束与流动粒子；无人机继续计算悬停消耗 |
| 60秒 | 双方坦克耐久100−6×16=4、弹药60−6=54；无人机能源60+24−2=82；保障车库存200−24=176 |

侧栏能源交付累计来自回放中的实际 `service` 事件；无人机能源、坦克血量和弹药来自已结算帧。前端只采样/显示，不再次裁决战斗。

支持暂停、0.5/1/2/4倍速、拖动进度、回到开头、点击单位定位、镜头拉近/拉远。
回拖至0秒恢复预演初始资源，不对现有对局重复扣资源。

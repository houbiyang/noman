# 手动对战真实地图接入进度

本轮继续开发现分支的手动对战功能，遵循用户“保留现地图、不修改地图”的决定。此前桥头接缝问题不再作为其他功能开发的前置条件，但未验证或不连续的连接不能被当作合法路线。没有修改总册、地图、桥梁、场景冻结摘要或用户数据库，没有合并、提交或推送。

## 本轮完成的代码

### 真实三角面射线证据

`backend/battle_occlusion.py`增加米制三维线段与真实网格的精确相交计算，使用有理数，包含普通穿面、共面穿越、擦边/顶点接触、薄面、近远命中排序和三维包围盒筛选。源目标面例外仅忽略对应单面在端点的接触，不排除整部件，也不忽略该面上的共面重叠。

适用总册地形模块7/8的遮挡基础：观察和射击需分别检查，观察者看见不能直接授予射手开火权限。真实资产已有摘要校验；证据带几何文件摘要。未分类部件不默认透明；缺面、无效输入、退化候选面或预算超限拒绝返回畅通结论。兵营/森林是否透明须由服务端明确目录提供，不能根据部件名字自行推断。

**边界**：这是遮挡基础组件，尚未注册到生产`Geometry`。局部部件命中可以证明对应面存在遮挡，局部未命中不能证明全场景畅通。`mesh_clear`只表示调用者提供的完整目录下没有网格交点，不证明目录已经验收、实体厚度完整、锚点在实体外、森林累计穿透长度合法或射手有攻击资格。结果始终不授予攻击权限或正式开战资格。

实地图测试读取现有地面、建筑和ROAD_004桥中段网格，确认地面/建筑穿面命中、桥下到桥上的垂直连线命中22米桥面、桥上方短线不误命中该部件。没有更改网格，没有证明桥头可通行或全图建筑实体已完整建模。

### 配置面板显示验收缺口

`manual_setup()`新增六项结构化检查：地表与遮挡层、移动与部署、桥面与连接、兵营/补给/据点、总册执行器接入、新局最终验收。

Unity配置面板使用现有深绿色检查卡片样式呈现“待完成 / 待核验 / 来源已验收”。空结果不默认通过，创建恢复锁定表单时仍可查看明细。地图项取自场景来源的明确布尔验收字段；“来源已验收”不代表本次部署已通过。只有对象已装配不能使执行器显示通过；尚无新局状态时不会制造假状态调用执行器。读取清单不发布、不写库、不开局，`can_create`仍为false。

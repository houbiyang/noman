## Git 版本管理

本目录是独立 Git 仓库，初始分支为 `main`。版本管理范围包含现行规格、页面原型源码与测试、设计素材和项目说明。Army_Editor、Gentactix-DSH 及移出的旧后端归档不属于本仓库。

根目录 `.gitignore` 排除本地数据库与凭据、环境配置、依赖目录、构建产物、缓存、日志及 `文档归档/` 历史备份；这些文件仍保留在本机。页面原型的 `package.json` 与 `package-lock.json` 纳入版本管理，`node_modules/` 不纳入。

在本目录的 PowerShell 中查看和保存后续改动：

```powershell
git status
git diff
git add -- 需要提交的文件路径
git commit -m "说明本次改动"
```

远程仓库为 [houbiyang/noman](https://github.com/houbiyang/noman)，对应远程名称 `origin`，主分支为 `main`。

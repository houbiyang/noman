# 穹图前端

本目录是 Vue 3、TypeScript、Vite 前端工程。默认入口直接进入本机服务端对战界面，自动创建演示对局并取得主持人席位；本机页面演示通过 `?view=demo` 单独访问。

## 本机运行

在 Windows PowerShell 中进入本目录后运行：

```powershell
npm ci
npm run dev
```

后端的运行与联调方式见 [后端运行说明](../backend/README.md)。本机启动脚本启用仅限回环地址的自动进入接口，由后端创建对局并签发当前席位会话；页面不接收创建权限密钥。令牌只在当前页面内存中保留，刷新后按地址中的对局标识重新签发，不写入浏览器存储。

构建检查：

```powershell
npm run build
```

当前代码的最小业务链路可在两个本机服务启动后，从工作区根目录执行：

```powershell
& .\backend\tests\smoke_local.ps1
```

后端源码更新后需重启后端进程，再运行该脚本。脚本经前端 `/api` 代理在隔离数据库新增一局随机首版正式对局，核对三席位投影、任务预览与提交、双方准备状态、命令结果和开局阶段；只输出对局标识与检查结果，不输出引导密钥或会话令牌。它不代替浏览器交互验收。

## 页面与模式

- `/?view=home`：保留的导航首页，提供“开始对战”和“打开之前的存档”。旧的 `?view=sandbox&mode=formal` 地址会返回首页。
- `/?view=live` 或 `/`：自动创建或进入本机服务端对局，显示当前席位的角色视图，并按服务端阶段与能力开放任务预览／提交、准备和开局命令。已有对局标识时可在页面切换主持人、红方或蓝方席位。
- `/?view=sandbox`：旧版原型地址，刷新后会迁移到 `/?view=live`，不会再作为正式用户入口。
- `/?view=history`：使用服务端席位令牌读取当前席位可见的正式对局目录；主持人可打开自动快照并进入只读复盘。
- `/?view=demo-saves`：读取本浏览器手动保存的页面演示进度，可返回 `/?view=demo`。该列表与服务端对局分离。
- `/?view=result&gameId=<UUID>`：读取已结束对局结果。
- `/?view=replay&gameId=<UUID>&step=<0-60>`：读取只读复盘帧；分支标识以服务端结果为准。

正式服务地址默认使用同源 `/api/v1`。Vite 开发服务把 `/api` 代理到本机后端 `127.0.0.1:18080`；临时联调其他本机后端端口时，可在启动 Vite 的 PowerShell 会话设置 `API_PROXY_TARGET`。需要不同公开地址时，可用 `VITE_API_BASE_URL` 指定**公开 API 地址**。不要把会话令牌或模型、数据库凭据放在 Vite 环境变量中。

## 当前边界

当前首页的“开始对战”进入服务端角色视图，“打开之前的存档”进入服务端历史目录；页面演示存档保留独立入口。首版正式场景已接入创建、三席位任务配置与准备、开局、历史和只读快照复盘。正式场景在真实智能体方案生成前停在等待确认阶段，不能执行演示方案、单步推进或正式存读档。演示场景可验证确定性巡查、暂停、结果和手动存读档。正式地图资源契约、真实建议、事件预览、四类任务完整规则和正式恢复仍待实现。`npm run build`、浏览器链路和完整业务验收分别记录，构建通过不代表完整业务验收通过。

本机浏览器席位验证可在正式场景后端和 Vite 服务启动后，从本目录执行 `node tests/live-ui-smoke.mjs`。脚本在隔离数据库创建随机正式对局，在独立的无界面 Edge 会话中验证红蓝准备、主持人开局、方案等待边界、历史和快照复盘；只输出对局标识和结果，不输出引导密钥或席位令牌。临时 Vite 服务使用其他端口时，可设置 `LIVE_TEST_ORIGIN` 指向该服务。

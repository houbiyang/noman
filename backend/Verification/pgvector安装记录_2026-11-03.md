## 独立安装

当前用户不能写入 `D:\PostgreSQL\18\lib`，本次没有提升权限或修改该目录 ACL。采用 [PostgreSQL 18 独立扩展路径机制](https://www.postgresql.org/docs/18/runtime-config-client.html)安装到用户本地目录。

实际物理目录记录在 `backend/.local/pgvector-installation.json`。本机 Windows 应用目录重定向后，安装位置为：

```text
C:\Users\80644\AppData\Local\Packages\OpenAI.Codex_2p2nqsd0c76g0\LocalCache\Local\Qiongtu\PostgreSQL18Extensions\pgvector-0.8.7
```

安装内容包括 `lib/vector.dll`、`share/extension/vector.control`、版本 SQL 文件及上游许可证。控制文件仅将 `module_pathname` 改为上述安装目录的绝对库路径，扩展源码与数据库 SQL 没有添加业务改动。

初始化器核对安装文件 SHA-256 后，通过 `ALTER DATABASE` 为明确目标库设置 `extension_control_path`，不改变实例全局配置。新业务库与临时验证／恢复库使用此设置；旧库保持原值。

## 重新部署

数据库备份不会包含 DLL、控制文件或编译组件。新电脑需先准备匹配 PostgreSQL 主版本和架构的扩展，建立正确的独立安装清单与路径，再执行 Setup 或数据库恢复。不能将当前电脑绝对路径直接当成另一环境的有效配置。

初始化器本身不会联网下载组件，也不会通过普通业务连接修改其他数据库。当前只交付表结构，正式后端、任务执行器和检索服务另行实现。
